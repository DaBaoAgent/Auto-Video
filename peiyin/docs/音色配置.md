# PeiYin 默认音色配置

## dabao

| 项 | 值 |
|---|---|
| 音色名 | `dabao` |
| 引擎 | GPT-SoVITS v5turbo zero-shot |
| 参考音频 | `GPT-SoVITS/voices/dabao/ref_dabao3-1.wav` |
| 预设 | `GPT-SoVITS/voices/dabao/preset.json` |
| 默认入口 | `GPT-SoVITS/dabao_tts.cmd` |
| 固定均衡 | 基础 320 Hz 中低频修正，叠加 70 Hz 高通、190 Hz `-4.6 dB`、380 Hz `-2.2 dB` 和 5 kHz 清晰度补偿 |

`lishi`、`weijie`、`dianying` 默认使用 `dabao`。调用方不传 `--config` 时自动读取该预设；均衡处理由服务端统一执行。

当前生产线只使用 GPT-SoVITS。
