# 出稿 + 配音工业化管线说明

> 本文是「徐艾伦 · 历史口播」项目的总管线文档：从选人物到配音归档，一条可复用的工业化流程。
> 关联文档：[口播稿规范](./口播稿规范.md)、[配音参数与音色](./配音参数与音色.md)、[配音审查门禁](./配音审查门禁.md)、[对标爆款拆解报告](./对标爆款拆解报告.md)、[钩子方案库](./钩子方案库.md)。

---

## 1. 这条管线做什么

以「历史人物口播」为内容形态（动画 + 克隆配音，账号：**徐艾伦**），批量产出：

- **口播稿**：`lishi/出稿/0XX_人物名/口播稿.md`（约 2500~3500 字 / 10 分钟级）
- **克隆配音**：`lishi/出稿/0XX_人物名/配音.wav` + `配音.json`（dabao 音色，GPT-SoVITS v5turbo 零样本克隆）

统一风格基线：

- 钩子开头（反常识提问 / 反差人设）
- 分节讲述 + 现代比喻（KPI、源代码、优化、上岸）
- 至少 1 句可截图传播的金句
- 结尾落到「这跟今天的你有什么关系」
- 结尾固定：**"我是艾伦，遛狗去了，白了个白。"**（"拜"读 bái）

## 2. 每篇生产流程（9 步）

```text
选人物 → 建目录 → 写口播稿 → 去AI味检查（两轮+门禁） → 转纯文本 → 配音 → 配音审查门禁 → 听审 → 归档
```

1. **选人物**：挑「有反差」的——你以为他是 A，其实他是 B（参考 `对标爆款拆解报告.md` 的选题标准；避免与已有编号重复）。
2. **建目录**：`lishi/出稿/0XX_人物名/`，编号顺序递增，不跳号、不重排。
3. **写口播稿**：按 `口播稿规范.md` 的七步骨架写，存入 `口播稿.md`。
4. **去 AI 味检查（两轮 + 门禁，必做）**：第一轮按 `AI味审核清单.md` 八大症状逐项自查并当场改；第二轮复查量化指标 + 朗读测试；两轮全过才放行，稿头状态标注"已过两轮 AI 味检查与门禁"（流程详见 `口播稿规范.md` 第 6 节）。
5. **转纯文本**：去掉标题 / 引号 / 括号，存为 `lishi/workdir/tts/XX_全篇.txt`（数字一律写中文，避免 TTS 读错）。
6. **配音**：按自然段分批合成，输出 `配音.wav` + `配音.json`。
7. **配音审查门禁**：运行 `scripts\check_dabao_audio.ps1`。任何硬门禁失败都必须回到对应段落重配，不能带病归档。
8. **听审**：听成品配音，重点复查接缝、专名和数字。
9. **归档**：完成后把整目录移入 `lishi/出稿/@已做/`。

## 3. 配音工具链

| 项 | 位置 / 值 |
|---|---|
| 长稿配音 | `scripts/synthesize_dabao_paragraphs.py` |
| 单段引擎 | `GPT-SoVITS/dabao_tts.py` / `dabao_tts.cmd` |
| 配音门禁 | `scripts/validate_dabao_audio.py` / `scripts/check_dabao_audio.ps1` |
| 参数配置 | `GPT-SoVITS/voices/dabao/preset.json` |
| 服务 | GPT-SoVITS tts_server（127.0.0.1:9880，音色由 preset / TTS_PRESET 指定，脚本自动拉起/复用） |
| 批量脚本 | `scripts/run_dabao_batch.ps1`（模板，改任务表即用） |
| 初始化 | `scripts/setup.ps1`（仓库内置 GPT-SoVITS + 模型/音色资源 + Python 3.11 venv + 冒烟测试） |

### 单篇配音（正式）

```powershell
& 'GPT-SoVITS\.venv\Scripts\python.exe' `
  'scripts\synthesize_dabao_paragraphs.py' `
  --text-file <全篇.txt> `
  --out <lishi\出稿\0XX_人物名\配音.wav> `
  --paragraph-gap-ms 200
```

自动完成：自然段拆分 → 逐段合成 → 句间静音压缩 → 噪声门 → 段间补 200ms 静音
（段首尾各保留 10ms 安全边）→ 拼接 → 输出 `配音.wav` + 带自然段时间轴的 `配音.json`。

### 配音后审查门禁（必做）

```powershell
.\scripts\check_dabao_audio.ps1 `
  -TopicDir <lishi\出稿\0XX_人物名> `
  -ExpectedParagraphGapMs 220
```

门禁依次检查：

1. 44.1kHz、单声道、PCM16、峰值 <1.0、削波为 0；
2. 口播稿、元数据和音频的段数、文本、时长一致；
3. 用 `small` 全片 ASR 回听，以无声调拼音序列做全文覆盖对齐；
4. 疑似漏点只抽取对应自然段，用 `medium` 再听一次，排除 ASR 同音字误报；
5. 固定收尾完整，配置了目标幕间停顿时再检查实际接缝误差。

输出 `配音审查报告.md`（人工可读）和 `配音审查.json`（含逐段 ASR 与判定依据）。
退出码非 0 即未通过，不允许归档。

### 批量配音（多篇）

```powershell
cd D:\@kaifa\PeiYin
.\scripts\run_dabao_batch.ps1
```

1. 把每篇纯文本放进 `lishi/workdir/tts/`（`XX_全篇.txt`）；
2. 编辑脚本中的「任务表」`$jobs`，追加 `@{ n = '0XX_人物名'; txt = 'XX_全篇.txt' }`；
3. 每篇合成后自动运行配音审查门禁，日志写入 `lishi/workdir/logs/batch_<时间戳>.log`。

## 4. 关键参数（2026-10-26 定稿 v5turbo）

| 项 | 值 |
|---|---|
| 音色 | dabao（徐艾伦克隆音，参考 `ref_dabao3-1.wav`） |
| 模型 | GPT-SoVITS v5turbo zero-shot |
| temperature / top_p / top_k | 0.9 / 0.9 / 20 |
| seed / repetition_penalty | -1 / 1.3 |
| speed_factor | 1.0（固定不改） |
| fragment_interval | 0.2（0.3 拖音、0.1 太硬） |
| 分句 | cut1，≤150 字/段；>6.2 字/秒判定截断，重配 ≤3 次 |
| 后处理 | 句间静音压至 100ms（>150ms 判定可压缩）、-40dB 静音门、-33dB 噪声门、段间补 20ms |
| 音色均衡 | 320Hz 宽频段 `-1.5dB`，4kHz `+1.0dB`，由 `voices/dabao/preset.json` 固化 |

参数沿革：10/23 用旧参数（temp 0.7 / top_p 0.9 / top_k 15 / speed 0.95 / seed 20261020 / rep 1.35）跑过伏羲、女娲首版；10/24 音色审核后定为 v3（temp 0.8 / cut1 ≤78 字），刘秀按 v3 重配，006 女娲～011 商汤按 v3 完成；10/26 起切 v5turbo 并定稿现参数（合段 150 字、fragment 0.2、temp 0.9），012 商纣王起统一使用。完整沿革见 [配音参数与音色](./配音参数与音色.md)。

## 5. 已知事项

- **tts_infer.yaml 不再被改写**：`tts_server.py` 已禁用配置回写；合成参数（temperature / top_p / top_k / speed / seed 等）由 `preset.json` 锁定，服务只按预设推理，命令行不再散传参数。
- **推理设备随环境**：`scripts/setup.ps1` 默认安装 CPU 版 torch 2.6，无显卡的机器也能跑；有 NVIDIA GPU 的机器可改装 CUDA 版 torch 提速，配音命令与参数不变。
- **音色由 preset 决定**：默认 `voices/dabao/preset.json`；通过环境变量 `TTS_PRESET` 或 `--config` 切换音色。`dabao_tts.py` 自动拉起/复用 tts_server，并校验 health 返回的 voice id，端口被其他音色占用时会明确报错。
- **三线默认音色**：`lishi`、`weijie`、`dianying` 默认都使用 `voices/dabao/preset.json` 中的 `dabao`，无需在各项目重复传音色参数。
- **批量配音用 `--keep-server`** 复用已启动的服务，省掉每篇约 1 分钟的模型加载。
- **配音后门禁不可跳过**：正式放行以 `配音审查报告.md` 的结论为准；跳过 ASR 只能用于调试。
- **多音字/误读修正**：`preset.json` 的 `speak_fixes` 字段维护「原文 → 正确读音」替换表（如 出降→出祥、荀彧→荀玉），新篇遇误读词可在此追加。
