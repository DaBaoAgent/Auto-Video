# 配音审查门禁

> 适用：`lishi`、`weijie`、`dianying` 的 dabao 长稿配音。  
> 原则：音频规格、全文覆盖、固定收尾任一失败，都不得进入听审或归档。

## 1. 标准流程

1. 用 `scripts/synthesize_dabao_paragraphs.py` 按自然段合成，保留段间时间轴。
2. 运行 `scripts/check_dabao_audio.ps1`。
3. 读取同目录的 `配音审查报告.md`。
4. 不通过时，只重配报告列出的自然段，再重新拼接并重跑门禁。

```powershell
& 'GPT-SoVITS\.venv\Scripts\python.exe' `
  'scripts\synthesize_dabao_paragraphs.py' `
  --text-file '<口播稿_定稿.txt>' `
  --out '<目录>\配音.wav' `
  --paragraph-gap-ms 200

.\scripts\check_dabao_audio.ps1 `
  -TopicDir '<目录>' `
  -ExpectedParagraphGapMs 220
```

`--paragraph-gap-ms 200` 再叠加每段首尾各 10ms 安全边，实测幕间为 220ms。

句间若残留明显呼吸声，可先运行局部气声清理，再重建自然段时间轴：

```powershell
& 'GPT-SoVITS\.venv\Scripts\python.exe' `
  'scripts\clean_dabao_breaths.py' `
  --audio-file '<目录>\配音.wav' `
  --metadata-file '<目录>\配音.json'

& 'GPT-SoVITS\.venv\Scripts\python.exe' `
  'scripts\rebuild_dabao_timeline.py' `
  --audio-file '<目录>\配音.wav' `
  --metadata-file '<目录>\配音.json' `
  --paragraph-gap-ms 200
```

气声清理只处理 VAD 判定为语音之外、能量高于 `-30 dB` 的区间，两侧保留
20ms 语音保护区；重建时间轴把幕间恢复为 220ms。重复“检测、清理、重建”，
直到 `--dry-run` 显示 0 段气声。

## 2. 硬门禁

- 音频必须为非空 WAV，44.1kHz、单声道、PCM16。
- 峰值必须小于 1.0，削波采样必须为 0。
- 定稿、元数据、音频三者的自然段数量和段落文本必须一致。
- 元数据时长与音频时长误差不超过 0.5%。
- 音色必须为 `dabao`。
- 指定幕间目标时，每个实际接缝必须在目标 ±25ms 内。
- 全文 ASR 覆盖不得存在成句漏读。
- 含固定结尾的稿子，结尾必须完整。

## 3. 漏读判定

门禁不直接比较汉字，因为 ASR 经常把同音字写成别的字。

1. 将原文按元数据中的 `spoken` 文本还原为实际朗读稿。
2. 原文和 ASR 都转成无声调拼音，并统一阿拉伯数字、年份、百分比。
3. 用拼音序列做全文对齐，连续缺失至少 4 个音节才进入疑似漏读。
4. 用 `small` 对整片做快速回听。
5. 只有疑似漏点所在自然段，才用 `medium` 再听一次。
6. 局部复听后仍缺失，才判门禁失败，并报告段号和原文片段。

英文缩写按中文近似音朗读时，门禁会把 ASR 返回的 `UFO`、`UAP`、`NASA`、`DNA`
分别归一为 `优艾弗欧`、`优诶皮`、`那萨`、`迪恩诶`，避免把成功的读音修正误判成漏读。

这样能抓到整句、半句和枚举项被跳过，同时排除“赵佗/赵驼”“白了个白/摆了个摆”这类
同音或近音误报。

## 4. 输出

- `配音审查报告.md`：人工阅读，显示通过/不通过、硬门禁、覆盖率和技术指标。
- `配音审查.json`：机器结果，包含 ASR 分段、漏读疑点、局部复听结果和音频 SHA256。

音频未变化时，门禁会按 SHA256 复用上次整片 ASR；改动音频后自动重新识别。

## 5. 返修规则

- 失败项写明自然段号时，只重配该段，不整片全量重跑。
- 枚举型漏读（多个“有人……”、并列短句）用
  `scripts/repair_dabao_paragraphs.py --clause-per-request` 逐分句合成。
- 重配后用自然段时间轴重新拼接，再跑完整门禁。
- 修复报告和 `配音审查.json` 一并保留，作为该期已过配音门禁的证据。

## 6. 限制

- ASR 用于发现“没配出来”，不能单靠它判断多音字是否正确；多音字仍按
  `GPT-SoVITS/voices/dabao/读音规范.md` 维护。
- 跳过 ASR 的 `--skip-asr` 仅用于调试技术规格，不能正式放行。
- 首次使用 `medium` 仲裁时，如果本机没有模型缓存，需要显式加
  `-AllowModelDownload`，避免门禁在后台无提示下载模型。
