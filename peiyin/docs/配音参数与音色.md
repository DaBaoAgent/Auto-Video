# 配音参数与音色（dabao · GPT-SoVITS v5turbo）

> 本文记录当前定稿的配音参数、调整沿革与工具链。
>
> **默认音色（2026-10-29 固化）**：`lishi`、`weijie`、`dianying` 三条线统一使用本页的 `dabao` 音色和 `voices/dabao/preset.json`，不要在各管线重复分叉音色参数。

## 1. 定稿参数（v5turbo，2026-10-26 起启用）

| 项 | 值 | 说明 |
|---|---|---|
| 音色 | **dabao** | 徐艾伦克隆音，参考 `ref_dabao3-1.wav` |
| 模型 | GPT-SoVITS **v5turbo** | zero-shot 克隆；CPU / GPU 均可运行，速度随设备 |
| temperature | 0.9 | 采样温度（较 v3 的 0.8 略松，语气更自然） |
| top_p | 0.9 | 核采样 |
| top_k | 20 | 采样候选 |
| seed | -1 | 随机 |
| repetition_penalty | 1.3 | 重复惩罚 |
| speed_factor | 1.0 | 语速，**固定不改** |
| 分句 | cut1 | 按句合并，**每段 ≤150 字**（约 2~3 句一段，保证连贯） |
| fragment_interval | 0.2 | 句间片段间隔（0.3 拖音、0.1 太硬，0.2 定稿） |
| 截断判定 | >6.2 字/秒 | 超速则重配 ≤3 次 |
| 句间静音 | 压至 100ms | >150ms 判定可压缩 |
| 静音门 | -40dB | 句间 |
| 噪声门 | -33dB / floor 0.3 | 底噪清理 |
| 段间补静音 | 20ms | 拼接衔接 |
| 音色后处理 | 基础均衡后叠加去喉音：70 Hz 高通、190 Hz `-4.6 dB`、380 Hz `-2.2 dB`、5 kHz `+1.6 dB`，并补 `+1.1 dB` 增益 | 2026-10-29 三档去喉音固化；完整处理链见 `preset.json`，由 tts_server 自动执行 |

## 2. 参数沿革（v3 → v5turbo 定稿）

| 版本 | 参数要点 | 结论 |
|---|---|---|
| v3_流畅起伏（v2 模型） | temp 0.8 / top_p 0.9 / top_k 20 / speed 1.0 / rep 1.3，cut1≤78 字 | 2026-10-24 定稿，用于 001 刘秀～011 商汤 |
| v5turbo 初始 | 模型升 v5turbo，参数沿用 v3 | 2026-10-26 用户更新 preset.json |
| v5_合段 | max_chunk_chars 78→**150** | 听感"一段段"→ 连贯句子合段（约 2~3 句/段） |
| v5_去拖音 | fragment_interval 0.3→0.1 | "我跟你讲"明显拖音 → 消除 |
| **v5_定稿** | fragment_interval 0.2 / temperature **0.9** | 拖音解决但语气硬 → 调松，自然流畅 |
| **dabao 固化** | 中低频 320Hz 轻微衰减 + 4kHz 轻微补偿 | 2026-10-29 三线统一，音色名仍为 `dabao` |
| **去喉音三档** | 在高通基础上加强 190Hz、380Hz 衰减，并补 5kHz 清晰度 | 2026-10-29 试听确认后固化到 dabao 预设与现有成片 |

定稿样音与临时分段已完成清理；后续以 `dabao` 预设直接生成新样音。

## 3. 误读修正表（speakFixes）

`GPT-SoVITS/voices/dabao/preset.json` 的 `speak_fixes.global` 维护「原文 → 正确读音」替换，新篇遇误读词直接追加。常见已收录类型：

- 古音/多音字：出降→出祥、投降→投祥、单于→蝉于、阏氏→胭脂、月氏→月支、龟兹→秋慈、吐蕃→土播、大宛→大渊、身毒→元毒
- 人名：荀彧→荀玉、张郃→张合、夏侯惇→夏侯蹲、沮授→举授、许褚→许楚、碽妃→公妃、朱橚→朱肃、许圉师→许禹师
- 地名：并州→冰州、兖州→演州、邺城→夜城、犍为→前为、长坂坡→常坂坡、濡须→如须
- 数字/符号：〇→零、100→一百、3D→三低
- 英文缩写：UFO→优艾弗欧、UAP→优诶皮、NASA→那萨、DNA→迪恩诶
- 编号：F A 十八→F十八、M Q 九→MQ-9
- 009 科学名词：缬氨酸→协氨酸、羊瘙痒症→羊痒病、β→贝塔、tau→涛

## 4. 工具链

| 项 | 位置 |
|---|---|
| TTS 主脚本 | `GPT-SoVITS/dabao_tts.py`（快捷入口 `dabao_tts.cmd`） |
| 参数配置 | `GPT-SoVITS/voices/dabao/preset.json` |
| 本地服务 | tts_server @ 127.0.0.1:9880，合成参数由 preset 锁定，脚本自动拉起/复用 |
| 批量脚本 | `scripts/run_dabao_batch.ps1` |
| 初始化 | `scripts/setup.ps1`（仓库内置 GPT-SoVITS + 权重校验 + Python 3.11 venv + 冒烟测试） |
| 气声清理 | `scripts/clean_dabao_breaths.py`（清句间高能非语音段） |
| 时间轴重建 | `scripts/rebuild_dabao_timeline.py`（恢复 220ms 幕间停顿） |

> 注意：`tts_server.py` 已禁用 `tts_infer.yaml` 回写，服务启动不会重置配置；temperature、top_p、top_k、speed、seed 等只从 `preset.json` 读取，换音色用 `TTS_PRESET` 环境变量或 `--config`。

## 5. 推理设备与速度

- **设备随环境**：`setup.ps1` 默认安装 CPU 版 torch 2.6，无 NVIDIA 显卡的机器也能完整运行；有 GPU 的机器可改装 CUDA 版 torch 提速，配音命令与参数不变。
- **速度参考**：原生产机（RTX 4070 SUPER）v5turbo 约 20~30 秒/段；CPU 机器按核数不同会明显更慢，批量配音建议用 `--keep-server` 复用服务，并查看 `lishi/workdir/logs/` 的批次日志。
