## 二、开头钩子：三种真实可套用的模板

### 模板①：「最快学历史」身份锚定型（张予不才 × 一代书生 都在用，重合度极高）

**原文对照**：

> 张予不才（秦始皇）："长脑子最快的方式，就是多看历史知识解读。接下来我将用三十六个月的时间，沉浸式分析古代君王的谋略……今天我们讲秦始皇。"

> 一代书生（张居正）："开窍的最快方式，就是多看我的历史解读。今天讲张居正。老规矩，先问大家一个问题——"

**公式拆解**：
```
[一句"学历史有用"的价值主张] + [今天讲XX] + [老规矩：先问一个问题] + [抛一个你以为你知道的常识] + [否定它："错/大错特错/根本不是"] + [抛出反常识答案]
```

**为什么有效**：
- 第一句就给观众一个"我在帮你涨知识"的功利性理由
- "老规矩"建立栏目感和追更习惯
- 否定句制造认知冲突，3秒内让人停下来

---

### 模板②：「你是不是觉得…大错特错」反常识型（一代书生嫡长子）

**原文**：
> "古代的皇位继承，为什么非得死磕嫡长子继承制？你是不是觉得，古代那些开国皇帝明明自己英明神武，却非要把皇位传给一个平庸懦弱甚至像晋惠帝那样连'何不食肉糜'都能说出来的傻子？嫡长子？肯定是因为他们老糊涂了对吧？大错特错。"

**公式**：
```
[一个反常识现象] + [复述观众的偏见：你是不是觉得…] + [把偏见推到极端举个蠢例子] + [下判断：大错特错/根本不是] + [抛出真实原因：他们是在给帝国焊保险丝]
```

---

### 模板③：「新人真诚+我跟你一样」自黑型（古人空间商鞅）

**原文**：
> "虽然现在只有零位粉丝关注，但我还是想勇敢地迈出这一步，挑战一个百万粉丝才敢碰的硬核话题——商鞅变法。我对这条视频很有信心，因为接下来我要讲的，绝不是两千多年前秦国发家的流水账，而是这片土地上历代王朝能够崛起、无数普通人能够逆天改命的升级底层代码。"

**公式**：
```
[自黑：我粉丝少/我是新人] + [但我要讲个大话题] + [立flag：这不是流水账] + [给一个和你有关的钩子：如果你觉得现在很卷/很累，看完你就懂了]
```

**为什么有效**：瞬间拉近距离，"如果你觉得现在很卷"直接把历史和观众当下的处境绑定。

---

### 钩子黄金三秒检查清单

每个开头写完后自问：
1. **前3秒有没有一句让观众"咦？"的话？**（反问、否定、极端数字、反常识）
2. **前10秒有没有点明"今天讲谁/讲什么"？**
3. **前30秒有没有给观众一个"为什么要继续看"的理由？**（涨知识/解疑惑/跟我有关）
4. **有没有出现"我"和"你"？**（打破独白感，建立对话）

## 三、主体结构：爆款是怎么搭起来的

以张予不才（秦始皇）和一代书生（张居正）为样本，拆出一个**七段式短稿结构**（7-10分钟版本，我们做动画3-5分钟可压缩为五段）：

```
【1. 钩子段】0-60秒
  抛问题+否定+反常识答案
     ↓
【2. 背景铺陈】60秒-2分钟
  "大家试想一下，在XX之前的X百年里，这片土地是什么样子？"
  关键：用"大家试想一下"邀请观众进入思考
     ↓
【3. 矛盾/抉择段】2-4分钟
  他面对什么诱惑？他看到了什么别人没看到的深渊？
  关键：把古人的抉择翻译成现代职场/人生选择
     ↓
【4. 动作段】4-7分钟
  他具体干了什么？用现代比喻解释
  关键：每一个历史动作都配一个现代商业/科技比喻
     ↓
【5. 结局段】7-8分钟
  他死了/败了/被清算
  关键：要狠要具体，不要"他死了"，要"他前脚刚死，后脚皇帝就抄了他家"
     ↓
【6. 翻转段】8-9分钟
  他错了吗？不——后世全部抄他的作业
  关键："嘴上骂着，身体却很诚实地沿用了他的制度"
     ↓
【7. 升华+跟你有关】最后30秒
  把历史落到现代：这跟今天的你有什么关系？
  关键：古人空间商鞅结尾落到"AI会不会淘汰程序员"
        张予不才秦始皇结尾落到"他发明了中国这个概念"
```

| 维度 | 子非秋月（已做过，避开） | 爆款新路线（艾伦动画号要走的） |
|------|------------------------|---------------------------|
| **视角** | 历史人物第一人称独白 | 艾伦本人吐槽解读 |

| **语气** | 文学化、沉重、悲剧美 | 口语化、网感、有态度 |

## 六、给徐艾伦号的五条落地建议

1. **固定开头模板用"模板①变体"**：把"长脑子最快的方式"换成艾伦自己的话，比如"遛狗的时候我老琢磨一件事"（D组钩子），既蹭了爆款公式，又绑定了遛狗人设。
2. **每篇必须有3个现代比喻**：这是知识区留住人的核心。历史事件不翻译成现代场景，观众3秒就划走。
3. **结尾一定要"跟你有关"**：古人空间商鞅结尾落到AI/程序员，这个结构值得抄——把古人的选择映射到今天打工人/内卷/焦虑。
4. **动画形式放大"动作感"**：克隆配音讲"他把桌子掀了"时，动画画面就真的画一张桌子被掀翻；讲"局域网并入广域网"时就画网络线连起来。这是动画号比真人解说号的天然优势。
5. **选题挑"有反差"的**：不选纯正面人物（岳飞文天祥可以做但不适合第一期），选那种"你以为他是A，其实他是B"的——比如李白（你以为他是洒脱诗仙，其实他是个一生想当官的官迷）。
