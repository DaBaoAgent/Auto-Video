# 已知坑（都是这一支片子实打实撞过的）

## 画

1. **圆角石碑像手机**。`roundRect` 画出来的石碑上沿是圆的，一眼是手机/平板。石碑必须直边：`lineTo` 走 ±.52w 底 → ±.96w@.62h → ±.90w@.935h → ±.76w@.985h → ±.28w@h 平顶。任何"石头/砖/板材"都先问自己：这个轮廓有圆角吗？有就是错的。
2. **分几块 `rect` 分别 `fill` 会留 0.5 px 亮缝**。相邻矩形在浮点坐标上不共边，缝里露出天空，整块就读成「石桌子」。石仓库必须**一笔外轮廓 + `evenodd` 挖门洞 + 门槛条**（`hw=w*.50, dw=w*.20, ph=h*.11, dh=h*.78, ch=h*.055`；底台 ±1.16hw、压顶 ±1.06hw）。
3. **黑剪影互相重叠必定并团**。两个剪影只要轮廓相接，就成一坨。站位要留空气：S7 的一个小人、S14 的仓库、S15 的巨人都是栽在这上面才改的构图。重叠是**设计**（比如巨人挡住小人）时也要确认挡住之后还读得出来。
4. **`both()` 里画 `destination-out` 会把 F 和 R 两层一起挖穿**。碑上的透光孔是刻意用这个特性做的（glyph 打孔让天空透进来）；反过来，任何"只想去倒影层"的擦除做不了。
5. **人物太近，腿出画成一根黑针**。宽檐帽考古学家原来 z 11.5，腿在画面下沿被裁掉，只剩一条黑线。改到 z 20.0 / x −1.55 才站得住。判断标准：**脚必须在画面里**，除非整条腿都在画外（那就别只露一截）。
6. **落点 y 不能凭感觉**。巨手把石件放进仓库门洞时，`py` 的落点是 **.78 而不是 .56**——因为石件底边要落在门槛（ph≈.22 m）上，而 `partAt` 在 S15 里固定 y=.48。写这种"手拿东西放进洞里"的镜头，先把**洞的口沿高度**算出来，再倒推手的高度。
7. **「走进日轮」是要算的，不是走过去的**。终点取世界 x −0.60：57.4 s 时 f≈5.2（fpx 5616）、z 44 → 该 x 的屏幕位 854 px，与日轮中心 859 px 重合。之前给 −3.0，人物只走到画面左侧。**任何"和日轮重合"都要换算屏幕坐标**（`W/2 + ((x-cx)/z - yaw) * f*H`）。
8. **冻结不是把时间停掉**：`tsOf(t)` 让主体时间停在 FZ、到 FZE 后再接着走；天空的 `ph` 和 `T` 继续喂。冻结期间手要**先落定再回撤**、冻结中挂着、解冻后才升走：`arm = .78 + 2.55*eio(env(t,53.06,53.40)) + 10.0*eio(env(t,55.60,56.30))`。
9. **字幕跟随音频，不跟随文稿**。原配音漏了「和现代科学测出来的只差十七分二十八秒」这句（RMS 能量检测证实）。处理方式：`--drop` 把它从脚本里删掉（`align.py` 会把前面的逗号改成句号），字幕严格跟音频；这句只在画面上做字（Anton 96 px，4.55–6.76 s）。**不要为了文稿完整去拉伸一条没人说过的字幕**。
10. **`subs=0` 才有无字幕帧**。`film.js` 里 `const NOSUB = /subs=0/.test(location.search)`，`still.mjs --q "subs=0"` 出封面帧；忘了这个开关，封面会带上烧录字幕。

## 声音

11. **`put()` 的 `gain` 别漏**。这一支片子的 `sound.py` 重构里就漏过一次：foley 事件的 `gain` 没传进 `put`，整条 foley 总线比谱面响 5 倍，峰值 3.9。现象是「mix 听着还行，但 foley stem 的峰值离谱」。
12. **噪声类音色的峰位每次不同**。所以两次渲染的 mix RMS 会差一点（实测 +1.4 dB）；要复现就把 `seed` 固定并接受这点差，或者用 `peak_ref: 0.999`。
13. **静默只切音乐**。`silences` 不切 foley 也不切人声；"一刀切"切的是音乐，水声要留着。

## 流程与环境

14. **`large-v3-turbo` 会重复幻觉**。长句中文用它转写，会把一句反复吐到段末，段落边界全错（`words_turbo.json` 就是这么废掉的）。默认 `small` 足够；要更强先读 `transcribe.py` 打印的尾巴。
15. **不要 `sh`/`bash`**。这台机器上直调 `sh` 会 MISS，`mux.sh` 必须走 PortableGit 的 `bash.exe`。这条管线**不用 bash**：两遍 loudnorm 用 ffmpeg 直接写进 `lvdong.py`。
16. **字体 404 会让渲染直接 exit 1**。`index.html` 里的 `@font-face` 指向 `fonts/`，所以 `fonts/`（`NotoSansSC.ttf` + `Anton-Regular.ttf`）必须跟着工程一起进 `$LIB/films/<slug>/`——`stage` 子命令负责干这件事，字体本身不入库（`lvdong/assets/fonts/` 被 gitignore）。
17. **直接打开 `styles/silhouette-rhythm/demo/index.html` 会 exit 1**（上游 demo 的字体路径不对外）。永远从 `films/<slug>/index.html` 进。
18. **PowerShell 对含换行/CRLF 的长串做 `-replace` 容易失配**。要么单行短串替换 + `Select-String` 验证，要么改 Node/Python。这一支片子最后全靠小脚本改的。
19. **`--fps` 别乱改**。30 fps / on-ones 是这套风格的基础，24 会让"落拍"变成"漂移"。
