# 画风：剪影律动（Silhouette Rhythm）这一段必须守住的东西

完整规范在库里的 `styles/silhouette-rhythm/STYLE.md`（`$LIB/styles/silhouette-rhythm/`）。这份文件只记**做片时真会用到的判据**，以及玛雅那一支片子定下来的具体数值。

## 一句话

> 纯黑剪影站在饱和的落日前面，**每一拍换一个姿势**；到关键那一拍全身冻结，只有天空还在走。水面是第二块画布：倒影、涟漪、逆光的水珠。

## 不能破的四条

1. **人物是一个黑块**：轮廓里没有细节、没有渐变、没有描边、没有阴影。观众读到的一切都在外轮廓上。
2. **永远有光在背后**：日轮、地平线亮带、水面碎金。剪影只能站在光里，不能站在暗处。
3. **姿势落在拍上，拍与拍之间是静止的**。一群人整齐地一起换姿势；谁不在拍上，那是故事的选择，不是失误。
4. **天空是时钟**：金 → 珊瑚 → 品红 → 紫，太阳跟着往下沉。颜色变化就是时间。

## 本管线（004 玛雅）定下的数值

| 项 | 值 | 说明 |
|---|---|---|
| 画幅 / fps | 1920×1080 / 30，全 on-ones | `K = H/1080`，所有像素量乘 K |
| 拍长 | 90 BPM，`B = 2/3` s；一小节 2.667 s | 段界取拍界，`beats` 子命令直接打表 |
| 墨色 | `#05020A`（带一点紫的近黑） | 人物永不变色 |
| 奶油 | `#FFF6DC` | 太阳/字幕/标签共用；不用纯白 |
| 剪影层 | `LF` + 倒影层 `LR` + 水面光层 `LX` | 由 `sky.js` 合成 |
| 倒影 | 同一形状镜像、裁在水线以下、alpha .52 | `both()` 一次画两层 |
| 日轮 | `sunR` .042–.045（约屏高 9%） | 长焦让它变大 |
| 焦段 | `f` 4.9–6.6（屏高倍数） | 特写用 6.4+，全景 5.2–5.6 |
| 地平线 | `hor` .58–.62 | 构图的一半靠它；一镜之内不动、不歪 |
| 机位高 | `ch` .80–.95 m | 平视水面 |
| 字幕 | 46 px `SCBold`，`#FFF6DC`，左下 `118*K, H-92*K` | 不带描边不带阴影，不进日轮 |
| 标签 | 34 px，`textAlign='center'` | 碑上两列的「雏形/成熟玛雅文」 |
| 画面大字 | Anton 96 px | 只用于 `17′28″` 这类一个数 |
| 混音 | −14 LUFS，TP ≤ −1.5 | mux 两遍 loudnorm |

## 网格（拍摄这些镜头时用的词汇）

| 动作 | 表达 | 用在哪 |
|---|---|---|
| 长焦、日轮占半幅 | 亲近、一个动作最清楚 | 开场、一个决定、屏住呼吸 |
| 贴水面的横移 | 一群人一起前进、腿与水花 | 行进、列队 |
| 侧视慢摇 | 一件接一件按顺序发生 | 流程、清点、交接 |
| 甩镜（方向模糊） | 注意力突然换地方 | 「与此同时」 |
| 高机位慢拉 | 尺度与孤独 | 后果、停顿 |
| 锁定中景 | 数拍子 | 数数、仪式、包袱落地 |
| 冻结中绕拍 | 从周围看那一刻 | 高潮、记录 |

换场只属于这个媒介：走近镜头的剪影（黑幕擦）、同一姿势的匹配剪、甩镜、直切进冻结。**没有叠化，没有翻页。**

## 这一段不做的事

- 不用 AI 生图、不用照片、不用素材片：天空、水面、涟漪、水珠、剪影全部由代码画。
- 不做片名卡（没有标题层）。
- 不加颗粒以外的后期（不加暗角、不加色偏、不加镜头光晕贴图）。
- 不为了「更像剪影」给人物补内轮廓细节。
