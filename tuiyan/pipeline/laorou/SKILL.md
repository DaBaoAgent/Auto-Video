# laorou 历史推演口播稿管线（alannew 适配版）

移植自 `D:\@kaifa\AutoYY\laorou`（老肉杂谈风格管线）+ `vendor/blader-humanizer`（去 AI 味，MIT）。
适配 alannew 项目「编剧层」：**输入 = 历史战争主题 + 史料调研**（不是纪录片 SRT）；**输出 = 20 分钟级老肉风格口播稿**（后续切分为 30-40 幕，喂给 battlefield-editor 数据层）。

> 上游更新时手动对比同步 `references/laorou-style-guide.md` 与 `vendor/blader-humanizer/SKILL.md`。

> **2026-10-05 用户规则更新（新规优先，覆盖上游风格指南中的相应旧规则）**：① 开场**直接进入历史剧情**："公元××××年的冬天"式时间＋对峙画面切入，不写刷手机/闲聊式由头；② 结尾**停用签名句**（不再写"（我是艾伦，遛狗去了，拜了个拜）"），以"好了，××的事，今天就先聊到这儿"式自然收束；③ 开场钩子段之后，带出系列介绍句：**"我是艾伦，准备用十年时间，好好讲完中国历史上的所有大小战争。"**

## When to Use

- 用户要给某个历史战争主题（赤壁/官渡/垓下/淝水…）写口播稿
- 要「老肉/闲聊科普」风格的文案或改写
- alannew 项目 M2 编剧层：主题 → 口播稿 → 分幕脚本

## 目标与字数

- 本项目默认：非空白 **5500-6500 字 ≈ 20-24 分钟**口播（上游纪录片版为 4500-5500；本项目按「20 分钟+」放宽，可用 `check_script.py --min/--max` 调整）
- 计数口径：`len(re.sub(r'\s+','',text))`（含标点）
- 素材不足不硬编，先明说缺口再补素材

## 六要素（写作时必须全中）

1. **开场直接入剧情**：不闲聊、不铺垫。用"公元××××年的冬天"式的时间＋对峙画面直接切进历史场景（一方是谁、另一方是谁、局势如何），2-4 句把张力拉起来。
2. **悬念定调**：场景之后抛"离谱/误会/反常识"钩子，明说"待会咱详细说"；每篇 1-3 个钩子型知识反转，且必须兑现。
3. **口语唠嗑推进**：短句一句一顿；靠"然后/再一个/另外/你像/完事/也就是说"推进；自问自答"那到底…呢？哎…"；预设观众疑问"可能有朋友已经想到了/有观众可能会有疑问"。
4. **引经据典译白话**：引史书原文一两句（建议单条 ≤20 字），**立刻翻译成大白话**，不掉书袋。引文宁可短、不可错。
5. **考据+纠正**：习惯性纠正流俗认知（"好多人以为…其实…"）；拿不准就明说（"学者们还在争论/推测是/没有定论"），不说死。
6. **自然收束**：结尾用"好了，××的事，今天就先聊到这儿"＋一句回扣；**不写签名句**（2026-10-05 起停用旧签名，见顶部规则块）。

**系列介绍句（2026-10-05 用户指定）**：开场钩子段之后自然带出："我是艾伦，准备用十年时间，好好讲完中国历史上的所有大小战争。"（系列期内每期宜保留，可微调措辞。）

通篇以艾伦第一人称"咱/我"叙述（不出现"老肉"自称）。

## 语气词/口癖弹药库（高复用）

句尾确认：是吧 / 就这么个意思 / 是这么个过程
转折设问：哎 / 那…到底是怎么回事呢 / 为什么呢？因为…
举例展开：你像 / 你想 / 比如来说
推进连接：然后 / 再一个 / 另外 / 完事 / 也就是说 / 说白了
感叹惊讶：就很离谱 / 太夸张了 / 谁能想到 / 就这么夸张
预告钩子：待会咱详细说 / 咱接着往下说 / 回头再细说 / 下面细说
不确定：推测是 / 还不太确定 / 学者们还在争论 / 并没有很明确的记录

（密度：3-5 句一个语气词，不每句都塞。）

## 结构模板（20 分钟版，约 6000 字）

1. **直入剧情+报题**（300-400 字）：时间＋对峙画面开场 → 悬念钩子 → 报"今天这期啊，咱就来好好认识一下XX"。
2. **系列介绍句**（50-80 字）：钩子段之后插入"我是艾伦，准备用十年时间，好好讲完中国历史上的所有大小战争。"
3. **身份定位**（250-400 字）：时间/地点/双方/兵力/结果一句话；为什么它是"转折点"。
4. **误区纠正**（800-1100 字）：挑 3-5 个"演义 vs 正史"反转逐条纠正，每条给"原来如此"。
5. **门道展开**（2800-3600 字）：战前局势 → 双方账本（谁算到了什么） → 过程（关键场面引原文） → 胜负手（分块讲透，每块先结论后机制，配生活化类比）。
6. **与人的关系**（600-800 字）：战后格局、人物结局、诗词文化影响、现实回声，落到"这事跟咱有关系"。
7. **收尾**（200-300 字）：一句回扣开场，自然收束（不写签名句）。

## 历史题材专项纪律（alannew 增补）

- **史实与演义分两个口径**："史书上写…" / "演义里说…" 不许混着讲；纠正类内容必须能指出出处。
- **引文短引**（≤20 字为宜），引完必译；长引容易记错字句，宁可转述。
- **数字全部用中文数字**；年份用"建安十三年（公元二零八年）"格式；不用阿拉伯数字。
- **关键事实落档**：写进 `content/<主题>/事实底稿.md`（每条含出处：书名·篇名），供复核与后续审核。
- **存疑不写死**：风向成因/疾病种类/地名争议等，必须用"还在争论/推测是"句式。
- **血腥一笔带过**：战场惨状点到为止（平台合规），不直给画面描写。

## 写作纪律

- **禁儿化音（铁律）**：主播艾伦是江苏口音设定，讲标准普通话，全文不写北方儿化音。**保留项**：近指/远指/疑问词"这儿/那儿/哪儿"、固定搭配"这里头/那里头"照常使用。高频坑：这会儿→这时候、那会儿→那时候、待会儿→待会、今儿→今天、明儿→明天、事儿→事、活儿→活、头儿→头、主儿→人/号人、大伙儿→大家、哥们儿→兄弟、爷们儿→男人、一会儿→一阵/片刻、门儿清→门清、玩意儿→东西、自个儿→自己、没准儿→没准、份儿→份、块儿→块（"坐一块儿"→"坐一起"）、地儿→地方。注意别误删"儿子/女儿/儿童/育儿/闺女/婴儿"等合法词。
- **事实锚定**：每个数字/人名/日期/引语都能在史料或调研资料里找到；找不到就不写或写模糊（"应该是/大概"）。
- **纯中文**：英文专名/人名/地名全部中文化；不用 em dash（——）；不夹英文。
- **无 AI 腔**：不用"首先/其次/综上所述/值得注意的是/本质上/不是A而是B"这类套壳句；不排比铺陈；不空泛升华。
- **短句为骨**：一句一个意思，能断则断；长短交错，避免整篇等长节奏。
- **推测与事实分开**："推测是/据记载"与断言分开写。
- **禁止原创**：不发明情节、数字、人物内心；拿不准的细节删掉，不补戏。

## 创作流程

1. **读素材 + 核验**：读史料调研结果；关键引文（原文、人名、数字）用检索核验一遍，疑虑处降级或删。
2. **列钩子**：挑 1-3 个最反常识/最有反转感的点做"待会细说"。
3. **起草**：按六要素+结构模板写，通篇艾伦第一人称唠嗑口吻；落盘 `content/<主题>/爆款口播稿.candidate.txt`。
4. **机检**：`python pipeline/laorou/scripts/check_script.py "<candidate 路径>" --min 5500 --max 6500`，全 PASS 才继续。
5. **Humanizer 过稿**：按 `vendor/blader-humanizer/SKILL.md` 的 Embedded 模式过一遍（内跑 draft→audit→final，只留最终文本）。
6. **事实复核**：逐条对照 `事实底稿.md`；新增事实补档。
7. **定稿**：写入 `content/<主题>/爆款口播稿.txt`，删除 candidate 草稿。

## Pitfalls

- **别把"老肉"写进稿子**：风格克隆老肉，自称必须是"咱/我（艾伦）"。
- **口语≠注水**：语气词调节奏，不靠重复凑字数，每段必须有新信息。
- **引经据典必须译**：引原文不给白话解释 = 掉书袋。
- **钩子必须兑现**：开场说"待会细说"的点，后面必须真的展开。
- **不许把演义情节写成史实**：典型反例——铁索连环、草船借箭（原型是孙权）、借东风、关羽放曹操、三气周瑜，全是演义加工。
- **结尾不写签名句**（2026-10-05 起）：旧签名"（我是艾伦，遛狗去了，拜了个拜）"已停用；结尾自然收束即可。
