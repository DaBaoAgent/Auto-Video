# 资产来源与许可

记录日期：2026-10-20（项目转为 HyperFrames 主导后的整理版）。

| 资产 | 来源与用途 |
|---|---|
| `content/` | 事实底稿、分镜与口播稿，项目内编写；史料来源见各 `事实底稿.md`。 |
| `三国人物/` | 项目方提供的 64 张人物原图，用作历史人物视觉。 |
| `assets/commanders/` | 由 `三国人物/` 原图裁切/统一生成的主帅卡；无影视剧照拼接。 |
| `assets/maps/` | 历史地形与地图示意素材，供 HyperFrames 画面复用；岸线、营寨、距离是可读性重建，不是精确古地理数据。 |
| `assets/brand/xualan.jpg` | 项目方提供的品牌头像。 |
| 旁白 | 本机 GPT-SoVITS **dabao** 预设（v3 底模 + 私人参考音频的零样本克隆）；参考音频与试听样音不随仓库分发。 |
| 配乐/音效 | 使用前逐一确认授权；旧 Canvas 管线的 `score.json` / `sfx-track.json` 已删除。 |
| `output/<slug>/narration*.mp3` | 各片旁白，dabao 生成；含私人音色，不随公开仓库分发。 |
| `output/<slug>/bed.wav` / 音效 | 原创音床与音效，脚本合成，无外部采样；可随片分发。 |
| `films/<slug>/vendor/fonts/` | Noto Serif SC / Noto Sans SC 可变字体，取自本机 Windows 字体目录；SIL Open Font License 1.1，发布前复核字体版权页。 |
| `films/<slug>/vendor/gsap.min.js` | GSAP 3.15.0；按 GreenSock 标准许可使用，发布前复核许可范围。 |
| `vendor/ai-animation-studio/` | 外部开源引擎（BogeLing/ai-animation-studio，MIT；内含 papermotion / brush，各自 MIT）。仅本地克隆，不入库。 |
| 画面素材 | papermotion 场景全部由代码生成，不使用外部图片、视频或音乐模型。 |
| 对标视频 | 仅做构图、信息层级与节奏研究，不复用帧、音频、字幕或图形素材。 |

公开发布前需要逐项确认美术、地图、字体、音乐和音效的授权范围。
人物原图与克隆参考音频属于私人素材，不要提交到公开仓库。
