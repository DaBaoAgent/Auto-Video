# labi · 蜡笔儿童绘本

一条片子 = **一页绘本正在被画**：蜡笔在暖白纸上走，一盒十几种蜡笔，儿童透视，颜色涂出线外，
每一帧都是新画所以线条轻轻**抖**。旁白不该是解说，而是**印在书页上的那几行字**。

示例工程：`projects/012_moon/`（《月亮睡不着》The Moon Can't Sleep，52 s，1248 帧 @24 fps）。

## 一句话记住

1. **质感来自材料物理**，不是滤镜：蜡只挂在纸齿的尖上，压力决定挂到多深；水彩被蜡抗拒。加一层假颗粒只会变脏。
2. **纸是主角**：暖白纸、纸齿锚在页面上（跟着镜头走），永不满画，底部留白给印字。
3. **一套有限的蜡笔**：十几支，线只有一种深色（靛蓝/深褐/梅紫），从不用黑；明暗靠压力不靠加色。
4. **画笔 12 fps 走，镜头 24 fps 走**：所有绘制的部分按 1/12 s 步进并重抖；镜头、水彩前沿、闪光每帧都在动。
5. **涂色就是动作**：盖上毯子 = 涂出格子毯；脸红 = 粉色乱涂；天黑 = 水彩洗过整页。
6. **画和涂是剧情**：不是先有场景再配图，而是「画出来 → 涂上去 → 洗出来」这件事本身推着故事走。

## 入口

在仓库根执行，单一入口 `labi/scripts/labi.py`：

```bash
python tools/sync_fonts.py --fetch && python tools/sync_fonts.py --pipeline labi   # 7 款手写体到位
python labi/scripts/labi.py probe  012_moon                      # 工程现状
python labi/scripts/labi.py stills 012_moon --times 0.5,12,40    # 静帧
python labi/scripts/labi.py render 012_moon                      # 无声母版 out/video.mp4（1248 帧）
python labi/scripts/labi.py mux    012_moon                      # 有 voice/voice.wav 时预母带 + 合流
python labi/scripts/labi.py srt    012_moon                      # 从 subs.json 导出 SRT
python labi/scripts/labi.py qa     012_moon                      # 六项质检
python labi/scripts/labi.py new    013_xxx                       # 复制骨架
```

参数：

| 子命令 | 参数 | 说明 |
|---|---|---|
| `stills` | `--times 0.5,12,40,49` | 逗号分隔的秒；输出 `out/stills/t_<秒>.jpg` |
| `render` | `--fps 24` `--start` `--end` `--out` | 默认按 `film.js` 的 `export const DUR` 出全片 |
| `mux` | `--video` `--voice` `--out` `--grain` | 没有配音就用默片；`--grain` 默认 0（纸齿就是颗粒） |
| `srt` | `--out` | 读 `subs.json`，`utf-8-sig` |
| `new` | `<slug>` | 从 `012_moon` 复制，忽略 `out/` 与字体 |

渲染交给共享运行时 `vendor/runtime/render-legacy.mjs`（与 caiqian / ditu / pingban / gangbi 同一份），
页面契约：`window.READY` / `window.DUR` / `window.EV` / `window.SUBS` / `window.render(t)`。

## 工程怎么改

`projects/<编号_名>/` 里七个文件分工：

| 文件 | 管什么 |
|---|---|
| `film.js` | 时间轴（`DUR`、`LINES`、`SUBS`、`EV`）、一次性镜头走位、每一拍画了什么 |
| `world.js` | 这一页的世界：房子、树、草坡、梯子、250 颗白蜡星、3 道水彩带 |
| `chars.js` | 角色（女孩的视角/表情/姿势、羊、月亮的表情与睡帽、毯子） |
| `rig.js` | 部件遮挡与 knock-out、肢体管、曲线 |
| `crayon.js` | 画笔：`line`（带收尖/细纹/boil 的带）、`fill`（锯齿排线，越界）、`text`、形状 |
| `gl.js` | WebGL2 合成：纸齿、蜡附着、knock-out、水彩 + 抗拒、浮雕/晕影/灯光 |
| `end.js` | 桌上的书、翻页、「The End」那张 |
| `pal.js` / `lib.js` | 调色板常量 / 数学工具（从 lemo 的 core/lib.js 落下，工程内自包含） |

改文案就改三处：`film.js` 的 `LINES`（旁白，`SUBS` 从它派生）、`film.js` 里 `ev(...)` 事件、`end.js` 结尾字；
字幕时间行改 `subs.json`，改完跑 `srt` 核对。

## 画面语法（选你要的那几条）

- **白蜡抗拒**：白蜡笔画在纸上看不见，洗过一次才露出来——第一帧就把它埋好，高潮时用一道水彩揭。
- **世界先画出来**：主角走在前面，脚下的路/梯子一段段自己长出来。
- **涂色就是动作**：把「上色」当成动词用（点灯 = 一格格涂亮；换季 = 一层绿洗过去）。
- **boil**：静止页也活着；片子要安静就把抖幅减半。
- **儿童逻辑**：山墙正面 + 侧墙斜贴、人比门大、数字写在天上、物件长脸。
- **这是一本书**：结尾拉远露出书和蜡笔、翻一页，一次成片的镜头就有了理由。

镜头词表：锁全页 / 推向角色 / 锁中近景 / 沿视线摇 / 紧跟随 / 稳住广角看刷子在动 / 慢移横读 / 越出页边拉远 / 翻页。转场只有画出来、涂上去、水彩、平移、翻页。**不用叠化。**

## 已知坑

1. **水彩带之间留白缝**，天停在草线上面——最后一道带必须压到草线；有纸的地方才有天。
2. **轻压涂的墙洗过之后发闷发蓝**——水彩会经过的区域压力 ≥ 0.8 或加交叉排线。
3. **写在天上的标题/数字会被水彩保住**（蜡抗拒），标题放广角不扫到的角落。
4. **头发上画轮廓线看成发箍**——只勾发块外沿。
5. **角色会淹进夜色里**（水彩钻进涂色缝）——角色在水彩**之后**合成。
6. **翻页用矩形条拼会出现阶梯**——每条要各自做仿射变换。
7. **书页转换处双重晕影/浮雕**——桌面那层从 0 渐入。
8. **屏固定的纸齿会让文件暴涨**（190 MB vs 74 MB）——必须锚在页面上，背景涂色不抖，不加 ffmpeg grain。
9. **笔记本从单元方差噪声造混响 IR 会巨响**——湿声压到干声下 18 dB。
