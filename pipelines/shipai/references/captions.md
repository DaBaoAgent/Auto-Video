# 字幕规范：一行、去标点、跟着真实语音走

## 版式（定版）

| 项 | 值 | 说明 |
|---|---|---|
| 显示行数 | **一次一行** | 不折行；太长就缩字号（60 → 最低 44） |
| 断句 | **按标点** | 一个短句一条，`，。、；：？！…` 都是断点 |
| 标点 | **不显示** | 渲染前统一剥掉 |
| 位置 | **画面下方 73% 高处**（y≈1402） | 不压住主体，也不贴底 |
| 描边 | **2px 黑色** | 亮背景（草地、浅天）不飘 |
| 阴影 | **黑色 0.15 透明度，偏移 2px** | 只压亮部，不做重投影 |
| 字体 | `MicrosoftYaHeiBold.ttc` | 与 MPT 的 `resource/fonts` 同款 |
| 字号 | 60px（最宽 0.91×1080 ≈ 983px） | 16 字刚好一行 |

渲染顺序：先落一层淡阴影（纯色无描边），再叠白字 + 2px 描边。顺序反了阴影会被描边吃掉。

## 时间从哪来

**只用 `timeline.json` 的 `clauses`**，这些时间来自 `vo_segment.py` 的「稿字 ↔ 转写字」对齐，是真实发音时间。三条硬规矩：

1. **不按字数均分**。均分在长句、语速变化、漏读面前一定漂。
2. **首尾相接**。`clauses[i].end = clauses[i+1].start`，最后一条 `end` 对齐切段末尾；不留空档、不重叠。
3. **只跟实际发音走**。稿子里有、配音没念的句子（本次是「和现代科学测出来的只差十七分二十八秒」）会被算成零长度，`vo_segment.py` 直接丢弃，不硬塞一条看不见的字幕。

## 一条字幕的诞生

```
timeline.json 的 clause ──► 去标点 ──► 按 0.91×宽 缩字号到放得下 ──► 一张 1080×1920 透明 PNG
                                                                    │
                                        ffmpeg overlay enable='between(t,start,end)'
```

PNG 是整帧尺寸，overlay 不用算坐标；字幕位置改 `--y-ratio` 就整体上下移。

## 已知坑

- **描边太细 + 亮背景**：1px 在白字压草地时边缘会「飘」。要保持细描边就加 0.15 阴影（本次的定版），要么把描边收到 2px 以上。
- **字号缩小要设下限**：无下限时一条 25 字的长句会被压到 30px，竖屏上不可读。`min_size` 44 是底线，超过就说明该再断句。
- **别用 MPT 的字幕链**：自定义音频下它拿不到 TTS 时间轴，字幕要么空要么错位；shipai 一律 `--no-subtitle-enabled` 后在外部烧。
- **字幕时间要复核**：`probe` 只查单调性，抽四帧（0.8 / 3.6 / 10.5 / 13.2 s）看位置与清晰度，别只看一帧。
