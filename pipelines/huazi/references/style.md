# huazi · 综艺花字

> 自研画法卡。写的是这种风格的规矩，不是某张参考图长什么样。

## 这是什么风格

综艺后期的情绪化字幕：填充色 + 粗白边 + 彩色外描边 + 投影，圆体胖字，高饱和撞色。

## 工序（时间轴）

花字的工序：先有画面（手持抖动 + 推镜）→ 按情绪出字 → 每字 pop 0→1.15→1 → 驻留时轻微 wiggle。

## 四条硬规矩

- 字层：外彩边 → 白粗边 → 渐变填充 → 投影，四层缺一层就不像花字。
- 入场：scale 0→1.15→1 约 8 帧，逐字错 2 帧，比画面晚 2～3 帧出现更自然。
- 情绪：惊讶用放射爆炸框，吐槽用倾斜手写，认证用红章。
- 画幅：1080×1920 竖屏，字压在安全区内，顶部留集数编号。

## 禁忌

- 不要细体/衬线字；
- 不要纯色单层描边；
- 不要让字匀速淡入。
