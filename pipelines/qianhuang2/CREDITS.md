# CREDITS · qianhuang2 铅黄剪影

## 画面

全部由本仓库代码逐帧绘制，**没有一帧 AI 生成图、没有一帧原片截帧**：

- `projects/<工程>/engine.js`：色板、光池 / 火盆 / 细环 / 投影、颗粒 / 污渍 / 划痕 / 暗角与 `post(t)`
- `projects/<工程>/cast.js`：骨架姿势表与三种人形（她 / 男人 / 倒地者）
- `projects/<工程>/world.js`：面具、营地、裂口、海湾、片名、胶片与收束六个场景
- `projects/<工程>/film.js`：`DUR` 与 `SHOTS` 镜头表

所有"随机"都走 `hash(t)` / `hash(i)` 这类确定性函数：同一秒、同一版代码，像素完全一致。

## 字

片名与副题使用系统字体（Microsoft YaHei / PingFang SC 回退链），**不随仓库分发字体文件**；换机器渲染前请确认目标字体已安装，否则会掉回默认无衬线。

## 声音

画面本身不带音效。成片的声音来自上游配音（示例样片用的是《血之海滩》第一段口播），
`mux` 只做电平对齐（−14.6 LUFS / 峰值 −1.6 dBFS），不合成任何采样。

## 风格来源

用光与色彩方法参考 1970 年代意大利铅黄（giallo）：

- Mario Bava《Black Sunday》(1960)：单点硬光、暗部整块塌进黑；
- Mario Bava《Blood and Black Lace》(1964)：色片侧光把人和物染成红/青；
- Dario Argento《Suspiria》(1977)：红绿原色的污染感。

本管线不复刻上述影片的任何镜头、不使用其任何画面素材，只迁移布光语法。
