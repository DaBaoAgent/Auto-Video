# gangbi · 钢笔淡彩

一条片子 = **一页当场画的速写**：深褐细线先画，水彩再盖上去，颜色永远比线慢半拍、偏一两个像素。
纸是主角之一——暖米色冷压纸，肌理、页边碎开、留白都是画面。

示例工程：`projects/012_wind/`（《风去了哪里》Where the Wind Went，33.4 s，1920×1080 / 24 fps）。

## 一句话记住

1. **线是提示，不是描摹。** 0.3–0.5 mm 针管笔，一根粗细差不多的线：抖一下、转角冲出去几像素、长笔画中间断一口。窗画三道，树只勾外沿的扇贝。
2. **水彩和线不重合。** 错位 1–3 px，有时越过线；边缘干得深一点（颜料积在边沿），颜料沉进纸齿。
3. **纸白是最亮的值。** 高光、人物、云肚皮全靠留白，不从颜料里调亮。
4. **颜色是事件，不是滤镜。** 每个像素有一个「颜色到达时间」；洗从源点扩散、前沿带湿边暗带。人物在被颜色碰到之前一直是线稿。
5. **静态的线拦不住后来的水彩。** 画近处东西前把里面的远线擦掉；远处人群用胡萝卜人（一坨色 + 两条腿 + 一个头点）。
6. **人物 12 fps 抖，页面不抖。** 线抖与彩种每 1/12 s 换一次；纸本身是纸，只有镜头每帧都在动。

## 入口

在仓库根执行，单一入口 `gangbi/scripts/gangbi.py`：

```bash
python gangbi/scripts/gangbi.py probe  012_wind        # 看工程现状（片长/字幕/字体/成片）
python gangbi/scripts/gangbi.py stills 012_wind --times 3,12,28   # 静帧，改了节拍先看这个
python gangbi/scripts/gangbi.py render 012_wind        # 无声母版 out/video.mp4
python gangbi/scripts/gangbi.py mux    012_wind        # 预母带 + 合流（有 voice/voice.wav 时）
python gangbi/scripts/gangbi.py srt    012_wind        # 从 subs.json 导出 SRT
python gangbi/scripts/gangbi.py qa     012_wind        # 六项质检
python gangbi/scripts/gangbi.py new    013_xxx         # 从 012_wind 复制一份新工程
```

参数：

| 子命令 | 参数 | 说明 |
|---|---|---|
| `stills` | `--times 3,12,28` | 逗号分隔的秒；输出 `out/stills/t_<秒>.jpg` |
| `render` | `--fps 24` `--start` `--end` `--out` | 默认按 `film.js` 的 `DUR` 出全片 |
| `mux` | `--video` `--voice` `--out` `--grain` | 没配音时跳过，或自己给一条 |
| `srt` | `--out` | 读工程内 `subs.json`，`utf-8-sig` 便于播放器识别 |

渲染交给共享运行时 `vendor/runtime/render-legacy.mjs`（与 caiqian / ditu / pingban 同一份），
页面契约与那三条一致：`window.READY` / `window.DUR` / `window.render(t)`，禁 `Date.now()`、`Math.random()`。

**渲染前字体必须到位**（字体不进仓库）：

```bash
python tools/sync_fonts.py --fetch
python tools/sync_fonts.py --pipeline gangbi
```

## 工程怎么改

`projects/<编号_名>/` 里四个文件分工：

| 文件 | 管什么 |
|---|---|
| `film.js` | 时间轴（`DUR`、段落、事件 `EV`）、镜头、草帽与人物表演、颜色到达的时机、结尾字 |
| `world.js` | 这一页的世界：公园的形状、树丛、桥、灯、远景，全部坐标在 5120×2880 纸面里 |
| `poses.js` | 人物姿势库（坐/跑/走/站/骑车/扑/趴/挥手），骨骼角度表 |
| `engine.js` | 笔与洗的引擎：`penStroke`/`drawPen`/`rasterPen`/`wash`/`reserve`/`dab`/`foliage`/`arrivalField`/`compositor`/`figure`/`handwrite`/`sketchShape` |

改文案就改两处：`film.js` 的 `NOTE`（角落手写注记）与结尾 `handwrite(...)` 的那句；
字幕行改 `subs.json`（`t0` / `t1` / `text`），改完跑 `srt` 核对。

## 画面语法（选你要的那几条）

- **线在色之前**：笔按真实笔顺画出主体，水彩随后落——画的过程本身就是表演。
- **颜色即事件**：水彩从源点扩散，事件把整页染色；人物在被碰到之前保持线稿。本示例就是「草帽把风带过去，风带过的地方才有颜色」。
- **唯一有颜色的东西**：全灰稿里只有一件上色的物件当主角（红伞、黄出租车、孩子的风筝）。
- **页当画框**：拉远到整页，页边碎开，页边空白里出现手写注记；结尾可以合上速写本。
- **胡萝卜人群**：远处人群压成一块水彩 + 两条腿 + 一个头点，不要画成一堆小人。

镜头词表：推近 / 横向弹簧跟 / 摇臂上升 / 甩镜带微滚 / 撞击短抖 / 拉回全页 / 摇进页边空白 / 只在线的区域慢摇 / 停住看笔 / 翻页。转场只有三种：镜头在纸上移动、翻页、颜色到达。**不用叠化。**

## 已知坑

1. **矩形裁剪会在颜色场上留下直边。** 颜色场要按真实的噪声距离裁，不是按包围盒。
2. **套在复杂轮廓外的矩形蒙版会留下缺口。** 用真实的台阶状轮廓做蒙版。
3. **人物走进没上色的区域会掉色。** 颜色到达时间在人物身上只采样一次（或绑到事件），别用当前位置实时采样。
4. **各种 IP 骨架在姿势混合时会劈腿。** 把脚的目标点往胯下混。
5. **正面头会秃。** 先画头发那一块，再把脸从里面挖出来。
6. **画满整张纸就没有速写感。** 必须留页边、让边缘碎成叶大小的点和白洞。
7. **字体没同步 → 手写字变成系统默认字体**，整页气质立刻塌。渲染前先跑 `sync_fonts`。
8. **大画布 + 无头 Chrome**：墨与时间自己打包进 RGBA 字节纹理，到达场用可过滤的 `R16F` 浮点纹理上传，别指望一张 5120×2880 的普通纹理能稳。

- [ ] 页边碎开、留出页边空白，没有画到边
- [ ] 人物 12 fps 抖，镜头每帧都在动，静止页不抖
- [ ] 手写注记与字幕都落在页边或下页边，不是浮层字幕框

- [ ] `python tools/validate.py` 这条管线 0 error
