# tanbi · 炭笔擦画

Charcoal, Erased and Redrawn

柳炭起形、纸擦笔揉开、可塑橡皮提白，再在擦掉的旧痕上重画一遍。

- 入口：`python pipelines/tanbi/scripts/tanbi.py --out out/tanbi.mp4 --seconds 7`
