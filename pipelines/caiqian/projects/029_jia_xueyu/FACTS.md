# FACTS · 029 假鳕鱼（彩铅科普插画）

口播稿里的每个数字，逐条对来源。**画面是示意，数字才要负责**：
鱼身、海床分层、鱼群的构图是画的，不是测量；凡是片子里说出来的量，都得有出处。

对象：鳕（大西洋鳕 *Gadus morhua*，鳕形目 Gadiformes）。片名里的"假鳕鱼"指消费者常混淆的"油鱼"
（异鳞蛇鲭 *Lepidocybium flavobrunneum* 等），两者不同科，片中以真鳕形态为主讲。

| 片子里的说法 | 状态 | 出处 / 说明 |
|---|---|---|
| 大约一亿两千万年前就长成今天的样子 | 待核（表述偏强） | 鳕形目的化石记录可追溯到白垩纪（约 1 亿年前后）。"已长成今天的样子"是修饰，不是化石证据；若要严格，应说"鳕形目出现得很早，形态此后变化不大"。 |
| 背鳍分开两三瓣 | 已核 | 鳕属背鳍 3 条，臀鳍 2 条，是鳕科识别特征（FishBase: *Gadus morhua*）。 |
| 臀鳍也分开 | 已核 | 同上，臀鳍 2 条。 |
| 这种体型游不快 | 已核（行为学常识） | 鳕属多为底栖、伏击式摄食，非巡航型鱼雷体形；与金枪鱼的纺锤形+尾柄形成对照。 |
| 一大群鳕鱼在深海里像兵蚁一样推过去 | 已核（群体行为） | 大西洋鳕有集群洄游与集群觅食记录。"像兵蚁"是比喻。 |
| 经过的地方寸草不生 | 待核（措辞夸张） | 大型鳕群确实会压减底栖小型动物密度（摄食压力），但"寸草不生"是修辞，不宜当结论。 |
| 那张嘴永远在嚼 / 连同类小鳕鱼都吃 | 已核（同类相食） | 鳕的食谱含鱼类、甲壳类、软体动物，胃含物中记录到幼鳕；同类相食在鳕科有记载。 |
| 雌鱼一次产五百万枚卵 | 已核（量级） | 大西洋鳕单次产卵量常引数百万枚（体长越大越高），"五百万"属常见量级表述；具体个体差异大。 |
| 孵化七十天 就能长大四十倍 | 待核 | 孵化期随水温变化（数周量级）；"七十天长大四十倍"未找到可引的具体测量，片中是示意节奏，若要上屏需换为可核数据。 |
| 欧洲渔民曾捕到两米长的 | 已核（记录量级） | 大西洋鳕历史最大记录约 1.9 m、近 100 kg；"两米"是口语取整。 |
| 现在还能捞到一米五、八十多公斤的大家伙 | 已核（记录量级） | 现代仍有个体达到 1.5 m、80 kg 以上的记录，属少见大个体。 |
| 海床分层（松散沉积 / 表层 / 下层 / 风化层 / 基岩） | 示意 | 按海洋沉积的一般层序画的，没有对应某一具体海域的取样。 |

## 引用口径

- FishBase（*Gadus morhua* 物种页）：背鳍/臀鳍数、体长体重范围、食性、产卵量。
- FAO Species Catalogue, Vol. 10（Gadiform Fishes of the World）：鳕形目分类与形态特征。
- 具体卷期页码待补：本表只写机构级来源，不做未经核对的引文。

## 片子怎么措辞

- 数字照口播原话，不改；有疑的（"一亿两千万年前""七十天四十倍"）在表里标"待核"，
  上屏前要么换数据，要么把句子改成不承担举证的说法。
- 画面永远比话多一点余量：说"两三瓣"就画三条背鳍，说"两米"就让鱼占满画幅的三分之二。
