# 抖音封面参考 · 10 种「有真人/有实景 + 文字」的排版拆解

全部为下载的真实封面样本（非 AI 生成），共 10 张，**每张都含人物或实景画面**。
目录：`refs/抖音封面参考/`（原图）+ `预览/`（1000px 长边缩略图）。
纯文字（无人像）的三张已移到 `纯字类（备选）/`：02 三层堆叠、03 深色木纹、04 顶部标签双行 —— 想走纯字路线时再用。

## 0. 平台硬约束（先定死，再谈风格）

| 项目 | 数值 | 影响 |
|---|---|---|
| 上传尺寸 | 1080×1920（9:16） | 竖屏全屏播放 |
| 主页封面 | 按 **3:4** 裁切（1080×1440） | 贴上下边缘的字在主页会被切掉 |
| 右侧遮挡 | 约画面宽 **12%–15%** | 点赞/评论/收藏/转发/音乐 |
| 底部遮挡 | 约 **400px（画面 21%）** | 文案、话题、音乐名 |
| 顶部遮挡 | 约 **140px（画面 7%）** | 作者名、进度条、标题 |
| 保守安全区 | 左 60 / 上 140 / 下 400 / 右 180 px | 所有字必须在这个框内 |

> 一句话：**字放上部 1/3 或中部、右边缘不放主标、底部 400px 别压字。**
> 3:4 和 9:16 并存时，标题须落在中间 3:4 区域 —— 这也是 fengmian 出双版的原因。

## 1. 逐张拆解（10 张全带人/实景）

### 01 · 背景字巨型 + 人像（知识讲堂）
- `01-背景字巨型-知识讲堂.jpg`（1242×1660，3:4）
- 版式：两个巨型字「知识/讲堂」铺满全幅当底纹，人像居中偏下立于字前；右下角竖排小标签（蓝底白字 @名字 + 竖排头衔）
- 字体：背景字=超粗黑（无描边，白色＋淡蓝外发光）；标签=常规黑体
- 字号：单字高≈画面 **45%**；标签≈**3%**
- 配色：深灰 #3A3A3A / 冷白 / 淡蓝光晕 #BFD9F2 / 标签蓝 #4A90D9
- 要点：**字当背景、人当前景**，缩略图里"知识"二字一眼可读

### 05 · 背景字 + 双色带（学好理科三个方法）
- `05-白底色带-理学三方法.jpg`（1242×1656，3:4）
- 版式：淡蓝巨型背景字（占 60% 画面）→ 人像居中 → 底部两条错位色带：白底粉字主标（8 字）+ 蓝底浅黄字副标（8 字，带手绘下划线）
- 字体：主标粗圆黑＋粉；副标圆体/手写味＋浅黄
- 字号：主标≈**6%**、副标≈**5%**
- 配色：浅蓝 #BFE1F5 / 粉 #FF6B9D / 宝蓝 #2C7BE5 / 浅黄 #F7E7A1
- 要点：底部色带 = 天然"信息条"，可承载副标且不脏画面

### 06 · 三格实景拼贴（学习博主）
- `06-实景拼贴-学习博主.jpg`（1242×1656，3:4）
- 版式：三等分横切三张实景（图书馆/书架/深夜书桌），每格压一组彩字：「学习/博主」深蓝＋黑双色、「高效」橘红、「12 小时」青绿；中格加白色气泡写三行小字
- 字体：超粗黑＋**粗白描边**＋轻投影
- 字号：字高≈**8%–10%**
- 配色：暖木实景 / 深蓝 #0F3D66 / 橘 #E2632A / 青绿 #2E9E8F / 白描边
- 要点：三张素材讲三段故事；描边是彩字压在实景上能看清的唯一办法

### 07 · 人物 + 顶部混色标题 + 右侧要点（考公上岸秘籍）
- `07-人物要点-考公上岸.jpg`（800×1067，3:4，分辨率最低）
- 版式：顶部两行超大标题（黄 4 字＋白 4 字，错位叠压）→ 人像半身居中 → 右侧竖排 3 个白底胶囊要点（绿勾）→ 底部白描边横幅大字
- 字体：标题**宋体加粗**（有衬线，正式感）；胶囊/横幅黑体
- 字号：顶部≈**9%**、胶囊≈**3.5%**、横幅≈**7%**
- 配色：暖白灰 / 黄 #F5C518 / 白 / 墨黑 / 绿 #34C759
- 要点：信息密度最高的一张，宋体让"上岸/体制"题材显得可信

### 08 · 浅底背景字 + 人像 + 底部双行（高数逆袭 90+）
- `08-背景大字-高数逆袭.jpg`（1242×1656，3:4）
- 版式：淡蓝超大背景字「高效学习」斜切铺底 → 人像居中 → 右侧蓝底白字气泡标签 → 底部两行白字（6 字＋6 字，含 90+）
- 字体：粗黑＋白字＋淡蓝投影
- 字号：底部主标≈**8%**
- 配色：米白 #F7F5EE / 淡蓝 #BFD9F2 / 中蓝 #4A7BD6
- 要点：浅色系封面在信息流里反而亮，女生/教育类常用

### 09 · 撞色三角 + 人像抠图 + 描边黄字（易瘦体质）
- `09-撞色描边-易瘦体质.jpg`（1125×2000，9:16）
- 版式：对角线切出黄/蓝/橙三角 → 上部两行黄字黑描边标题 → 人像抠图居中压在色块 → 底部白纸条＋蓝字副标
- 字体：超粗黑＋**黑描边**（黄字黑边，撞色最强）
- 字号：标题≈**7%**
- 配色：黄 #FFC400 / 宝蓝 #1F4FA8 / 橙红 #D9481F / 黑描边
- 要点：几何切块＋抠图＝零素材也能做，冲击力最强但偏娱乐

### 10 · 综艺爆炸框 + 人像（场面失控）
- `10-综艺爆炸框-场面失控.jpg`（1125×2000，9:16）
- 版式：橙黄放射底＋白色锯齿爆炸框 → 主标 4 字（天蓝＋白描边）在框内 → 副标在黄胶囊 → 顶部三个小三角 → 人像半身在下
- 字体：卡通粗圆＋重描边
- 字号：主标≈**9%**
- 配色：橙黄 #F6B042 / 白 / 天蓝 #79B8E8
- 要点：情绪型封面，适合娱乐/综艺，**不适合严肃纪录片**

### 11 · 三段式：顶标题 + 双人 + 底黑条（未来楼市预测）
- `11-商务双人-未来楼市.jpg`（1242×1660，3:4）
- 版式：顶部单行黄字黑描边标题（9 字，占宽≈92%）→ 中部两位西装人像抠图（蓝玻璃幕墙背景）→ 底部**纯黑条**内两行（白 9 字＋黄 8 字）
- 字体：顶部粗黑＋黑描边＋亮黄填充；底部常规黑体，无描边
- 字号：顶部≈**7%**、底部两行≈**5%**
- 配色：天蓝 #2E7BC4 / 亮黄 #FFD400 / 黑描边 / 黑条 #000
- 要点：**双人＝权威感**；底部黑条是"信息区"，视频文案/结论可以塞进去

### 12 · 左右分栏对比（卖点 vs 买点）
- `12-左右分栏VS-生意窍门.jpg`（1242×1656，3:4）
- 版式：顶部蓝色超大标题（8 字，被人物头顶遮挡一部分）→ 人像右侧站立（抠图带黄描边）→ 左侧竖排三行：白字黑描边「卖点思维」／黄色粗斜体「VS」／「买点思维」
- 字体：顶部圆黑（蓝＋白描边）；左侧黑体白字＋黑描边；VS 为黄色粗斜
- 字号：顶部≈**9%**（几乎顶满宽）；左侧每行≈**4.5%**
- 配色：米墙 #E8E2D8 / 蓝 #1E6FD9 / 白 / 黄 #FFD400 / 人物黄描边 #FFC93C
- 要点：**对立型选题的最佳结构**（A vs B、对 vs 错、旧 vs 新），一眼看懂

### 13 · 顶部小图带 + 双人抠图 + 底白字（整个夏天）
- `13-顶部小图带-双人抠图.jpg`（1242×2208，3:4 偏高）
- 版式：最顶一行手写小标语 → 横排 3 张实景小图（约 22% 高）→ 橙色底 → 两个人像大抠图（白描边＋投影）→ 底部两行白字黑描边
- 字体：底部粗黑＋白字黑描边；顶部手写圆体
- 字号：底部主标≈**7%**
- 配色：橙 #F2A33C / 白描边 / 黑描边 / 蓝灰实景
- 要点："先证据（小图）后人物（大图）"，情感/旅拍/Vlog 类最好用

## 3. 通用结论（可直接套的数值）

1. **字号**：9:16 主标字高 ≥120px（画面 6%+）；3:4 ≥90px。一行不超过 8–9 字，最多「2 行主标 + 1 行副标」，副标取主标 60–70%。
2. **人物处理**：人像一律**抠图 + 白/黄描边 + 投影**再压字（06、09、12、13 全是这么做的），否则人像和字糊在一起。
3. **字压在实景上**只有两种解法：加**粗描边**（06/12/13），或让字退到底层当背景字（01/05/08）。
4. **配色家族**只选一个：黑金（厚重）/ 蓝黄（商务权威）/ 浅蓝（轻知识）/ 撞色（娱乐）。
5. **信息条**：底部黑条或色带（05/11/13）能多塞一行副标而不脏画面，最长用的一招。

## 4. 与 fengmian 现有版式的关系

fengmian 当前是「6 字金黄毛笔主标 + 8 字白毛笔副标」压顶部，等效于纯字系的 03/04。
换成"有人/有图"这一路，最稳三条：
- 想权威厚重 → **11**（顶黄字描边标题＋中部人像＋底部黑条双行）。
- 想讲对比选题 → **12**（左右分栏＋VS，一眼看懂对立）。
- 想保留质感又要人 → **01**（把主标做成巨型背景字，人像压在上面，最小改动）。
