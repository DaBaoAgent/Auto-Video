# map 管线 · 验收清单

## 技术指标

| 项 | 目标 | 检查方式 |
|---|---|---|
| 分辨率 / 帧率 | 1920×1080 / 30 fps（样片可 1280×720） | `ffprobe` 或 `python scripts/map.py probe <mp4>` |
| 时长 | 旁白时长 + `lead_in` + `tail`，误差 < 0.2 s | probe 与 `timeline.json` 对比 |
| 响度 | −16 LUFS（有旁白）/ 约 −1 dBTP | `deliver.py` 的 loudnorm |
| 黑帧 | 0 | `blackdetect=d=0.1:pix_th=0.10` |
| 解码 | 无错误 | `ffmpeg -v error -i <mp4> -f null -` |
| 字幕 | 每句齐全、不重叠、单行 ≤ 18 字 | `out/captions-16x9.srt` |

`deliver.py` 会把以上结果写进 `<工程>/review/qa.json`。

## 画面

- [ ] 所有路线都标了「方向示意，非实测路线」（片头一次或常驻角标）。
- [ ] 人物站在路线/城市的**上方**（不是南侧），贴纸在卡片之上、字幕之下。
- [ ] 地球阶段没有贴纸被挤到球缘。
- [ ] 地名标签不压在字幕带、章节条、角落家具上。

- [ ] 抽帧看过：地球 → 区域 → 城市 → 街道，每次镜头飞行都看过 `--strip`。
