# map 管线 · 漫画贴纸资产规范

> 来源：025《张骞寻路》全片（2026-11-06 经 5 轮迭代后固化）。本文是 map 管线的通用贴纸规范；
> 文中「本项目」示例均指该实例 `projects/zhangqian/`，新片按同样字段改写即可。

---

## 1. 一句话原则

**所有人物、道具、地形都是用 SVG 代码画出来的漫画贴纸**；地图是论证主体，贴纸锚定真实经纬度，按旁白逐句落位；**人物与道具必须在路线与城市的上方**（既是层级、也是画面位置）。不使用图像生成、不使用位图素材。

## 2. SVG 资产规格（硬性）

| 项 | 规格 |
|---|---|
| 画布 | `viewBox="0 0 400 400"`，`width/height=400` |
| 背景 | 透明，无底板、无投影 |
| 描边 | 统一 `#2E2924`，根 `<g stroke-width="4">`，`stroke-linecap/linejoin="round"` |
| 上色 | 平涂分面（本色 + 一块暗面 + 少量高光），**不用渐变、不用写实光影** |
| 构图 | 主体居中、完整不裁切；贴纸有纸色光晕由页面负责，SVG 内不画 |
| 文件 | `NN_english_name.svg`，NN 两位序号；纯 ASCII 文件名，中文说明放审核页 |
| 复用 | 多实例用 `<defs><g id="…">` + `<use href="#…" transform="translate(…) scale(…)">`（03 五骑即此法） |
| 校验 | XML 可解析 + 浏览器实际渲染截图确认造型可辨、无破碎/溢色 |

## 3. 图层与位置（**最易错，勿改回**）

map runtime 的 root（`stage.firstElementChild`，`z-index:1`）内部层级：
```
主 canvas（底图/水线/路线/G.draw）  <  svg(3)  <  over(4)（地名·卡片·图例·note）  <  资产层(5)  <  纸纹/暗角(6)
```
- 资产层必须 `z-index: 5` 并 append 进 **map root**（不是 stage），否则会被卡片整体盖住或落到地图下面。
- 字幕在 stage 级 `z-index 870+`，永远在贴纸之上 ✓。

**位置根因**：贴纸用 CSS `transform: translate(tx,ty) scale(s)` 定位，`translate` 移动的是**元素左上角**，元素从锚点 `(x,y)` **向下展开**；`transform-origin: 50% 100%` 只影响 scale 中心，**不改变 translate 语义**。所以：
- 只调 `z-index` → 贴纸压住红线，但整只人仍落在线的**下方（南侧）**。
- 只调 `dy`（十几像素）→ 杯水车薪。
- 必须给人物加 `lift`（约 0.8–0.9 × 贴纸宽度），把整只人抬到锚点上方：
  ```
  ty = y - A.dy - (A.lift || 0)
  ```
  本项目实测：`张骞 200 / 汉武帝 215 / 古代背夫 170`（px，1920 基准）。
- 道具与地形**不加 lift**，否则 5 骑会顶到「一万二千里」标题。
- globe 阶段（zoom < `globeZoom 3.6`）`G.at()` 是正交投影，贴纸会被挤到球缘 → **人物出场必须晚于地图展开**（本项目 `a1+1.8`）。

## 4. 动画配置（固化接口）

资产层配置一行一个实例，字段：
```js
{ f: '01_zhangqian.svg',          // 文件名（assets/models/ 下）
  ll: [108.94, 34.34],           // 静态锚点（经纬度）；与 path 二选一
  path: HOMEWARD, from: 2.5, to: 4.9,  // 移动：路径 + 起止时间；到点后停到 until
  w: 240,                        // 贴纸宽度 px（1920 基准）
  at: 2.5, until: 5.4,          // 出现 / 消失（0.5 s 淡入、0.45 s 淡出）
  dy: 20,                        // 脚部相对锚点微调
  lift: 200 }                    // 人物专用：整体上抬，见 §3
```
- `pathAt(points, u)`：按**弧长**插值，避免各段长短不一时速度跳变。
- `easeMove(x) = x²(3−2x)`：起步与到达都平缓。
- `G.onFrame((t,g) => …)` 每帧用 `g.at(ll)` 求屏幕坐标，**纯函数、不用 Date.now / CSS 动画**。
- `await Promise.all(imgs.map(el => el.decode()))`：避免前几帧贴纸未加载。
- 同一资产可有多个实例（04 竹杖：静态 l2–l5 + 移动 l6）。

## 5. 旁白与字幕对齐

- 用用户原声 `配音.wav`，**不重新 TTS**。
- 段落边界：`ffmpeg -af silencedetect=noise=-38dB:d=0.22` 找约 0.23 s 的段间停顿。
- 句边界：段内按字数比例预测，再在 ±0.9 s 窗口取短时能量最低点校正；字级时间按字符均分。
- `-t` 必须放在 `-i` **之前**（输入截断），否则 `adelay` 加的片头留白会被从**尾部**削掉，末句被切。
- 本机 ffmpeg 的 native AAC 编码 **44.1 kHz 单声道会永久卡住**：先 `-ar 48000 -ac 2` 再编码。
- 输出 `audio/narration.m4a` + `timeline.js` / `timeline.json`；`script.json` 写 `"bgm": false`。

## 6. 分镜与事实

- 所有屏幕文字必须能在 `brief.md` 找到；最省事的做法是把**口播稿相应段落全文**写进 brief.md，屏幕文字一律取原文短语。
- 示意路线（官方北线、物证连线、秘道）必须带「示意 / 方向示意，非实测路线」标注，不冒充实测古道。
- 底图用 `await G.world({ detail:'50m', states:false })`（Natural Earth，public domain，自动署名）；`globeZoom: 3.6`。
- 一条连续镜头：`G.camera([{at, center, zoom, dur}…])`；地名标签按**镜头能看到它的那一段**分段设 `at/until`，否则会被 `--check` 判「标注出画」。
- 角落家具 `tl / tc / tr / bl / br` 要错开，避免 note 与卡片重叠。

## 7. 渲染 / 混音 / QA

```bash
# 自检（不渲染画面；长片含整片配乐合成，可能要几分钟）
python scripts/map.py check <工程>
# 快速抽帧（改动画后必做）
python scripts/map.py stills <工程> --times 3,7.5,16.5,25,27.5
# 渲染：1080p 成片；样片用 --scale 0.6667 → 1280x720
python scripts/map.py render <工程> [--scale 0.6667]
# 混音（BGM 自动 -stream_loop 循环铺满长片）
python scripts/map.py deliver <工程> --chugao <出稿目录> --name <交付名> --bgm <bgm.mp3>
# QA：ffprobe 时长/分辨率/帧率 + loudnorm + blackdetect + ffmpeg -f null 解码
```
- 渲染进程在打印「完成：…」后**收尾（封面/字幕导出）常挂起**：确认 ffprobe 帧数完整后终止进程，自行用 ffmpeg 抽帧补封面、从 timeline 生成 SRT。
- 目标：**-16 LUFS / 约 -1 dBTP / 黑帧 0 / 解码 OK**。
- 每轮渲染前备份上一版成片（v1/v2/… 链）。

## 8. 已知坑速查

| 现象 | 原因 / 处理 |
|---|---|
| ffmpeg 卡在 AAC 编码 0.67 s | 44.1k mono → 先转 48k stereo |
| 最后一句被切掉 | `-t` 放到了 `-i` 后 |
| 找不到 Chrome | `CHROME_PATH` 指向本机 Chrome/Edge（技能只探测 macOS/Linux 路径） |
| 贴纸出现在地球边缘 | globe 阶段不要显示贴纸，出场推迟到地图展开后 |
| 巨大同心圆压住地名 | `G.travel` 不传 `size`，默认 1 |
| 收尾挂起 | 见 §7 |
| Bash 的 `curl` 不通但浏览器能加载 CDN | Python urllib / Chrome 可访问，字体与世界底图不受影响 |
