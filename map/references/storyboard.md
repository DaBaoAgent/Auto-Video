# map 管线 · 分镜写法

一页分镜要能让执行者不问问题就做出画面。张骞实例见 `../projects/zhangqian/storyboard.md`。

## 1. 事实表先行

`brief.md` 是唯一事实来源：

- `## Sources` 列清楚配音、口播稿、底图数据、制作规范的文件路径与许可。
- `## 旁白原文` 按自然段全文贴入。**屏幕上出现的每一个字都必须能在这里找到**；`--check` 会逐条核对，找不到就报错。
- 创意文案（标题、旁注、图例）单独成节，标明「文案」，不要混进事实。
- 示意路线、推测位置在分镜与画面里都要写「方向示意，非实测路线」，不冒充实测。

## 2. 信息清单

观众看完要记住的 3–6 件事，每条对应若干自然段。写成：

```
1. 结论 A（段 1–4）
2. 结论 B（段 5–9）
```

没有信息清单的分镜不许开工——画面会变成「地图上飘字」。

## 3. 段落时间轴

| 段 | 起止 (s) | 主题 | 镜头中心 / zoom | 贴纸 |
|---|---|---|---|---|
| 1 | 0.70–32.65 | 报告与秘道 | [90,36] 4.5 → [70,35] 5.7 | 张骞、汉武帝 |
| 2 | 32.88–48.20 | 买马 | [92,35] 4.6 | 无 |

- 时间取 `paragraphs.js` 的 `start/end`（已含片头留白），不要手写。
- 一条连续镜头：每一段至少给一个 `center/zoom`（或 `fit`），长片也不要切成硬切。
- 镜头飞行不超过每秒 2.5 个 zoom 级别；`--check` 会报出过快的镜头。

## 4. 贴纸表

按 `asset-spec.md` 的字段写，每个实例一行，注明「谁动谁不动」：

| 贴纸 | 行为 | 锚点 / 路径 | 起止 |
|---|---|---|---|
| 主角 | 沿官方北线反向移动，到达后淡出 | `HOMEWARD` | a1+1.8 → a1+4.7 |
| 帝王 | 固定不动 | [108.94, 34.34] | a1+2.4 → a2+0.3 |
| 道具 | 固定在集市 | [68.5, 33.6] | a2+0.75 → a6 |

规则：

- 人物必须 `lift`（约 0.8–0.9 × 宽度），否则会落在路线南侧。
- 地形/道具不加 `lift`。
- 地球阶段（zoom < `globeZoom`）不要显示贴纸，人物出场至少等地图展开 1.8 s。
- 同一资产可以多实例（静的 + 动的），不要复制 SVG 文件。

## 5. 屏幕文字

- 每段至少一个大件：`G.callout` 标题（38–48 px）、`G.year` 大数字、图例数字、`G.title`。
- `G.note` 只做一句短注，字号 ≥ 30 px。
- 左上/右上/左下/右下角家具（`tl/tc/tr/bl/br`）要错开，避免 note 与卡片重叠。
- 所有文字在 `--check` 里会核对 brief.md；先改 brief 再改画面。

## 6. 声音

- `score.js` 写一句这支片子的配乐是什么（`name` 字段），再按它改声部；模板原文会被 `--check` 提醒。
- `sound.js` 同理，写一句音效设计。
- 长片配乐由渲染器整片合成；`script.json` 的 `bgm: false` 只关掉内置背景音乐，不关音效。

## 7. 交付前

- `--check` 无 error（warn 逐条确认）。
- 抽帧看地球、区域、城市、街道四个层级，以及每次贴纸出场/移动。
- 成片跑 `scripts/deliver.py`，QA 写进 `review/qa.json`。
