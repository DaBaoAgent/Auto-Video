# 12 · 印章落定

## 画面

大片空纸。上方一行朱砂小字（引子），中间一行大字（结语），下面一条旧金细线，
线下落款「纪年 · 季节」，右侧一枚朱砂印章砸落。

## 运动

| 时刻 | 动作 |
|---|---|
| 0–18f | 朱砂引子淡入 |
| 10f 起 | 大字逐字入场（96px，stagger 3f，dur 18f） |
| 34–60f | 旧金细线从中心向两侧展开到 440px |
| 40–60f | 落款淡入 |
| 52f | 印章砸落（scale 1.62→1，7f，rotate -6°） |
| 全程 | 纸面 1.03 → 1.00 微缩（`zoom`） |

## 参数

| 项 | 值 |
|---|---|
| 引子 | 42px，楷体，朱砂，`letter-spacing: 0.5em`，`top: 330` |
| 大字 | 96px，`letter-spacing: 0.1em`，`top: 462` |
| 细线 | 440px × 2px，`GOLD`，opacity 0.75，`top: 632` |
| 落款 | 26px，`ink(0.42)`，`letter-spacing: 0.44em`，`left: 740, top: 664` |
| 印章 | 104px，`left: 1112, top: 690`，`delay: 52` |

## content 槽

| 键 | 赤壁取值 |
|---|---|
| `kicker` | 那一年 |
| `line` | 我输掉的不只是一场仗（11 字上限） |
| `date` | 建安十三年 · 冬 |
| `seal` | 曹操（2 字） |

## 已知坑

- **印章不能压落款。** 落款 `left: 740` 起、字距 0.44em，7 字到 x≈1090；
  印章必须 `left ≥ 1112`。第一版印章压在「冬」上。
- **印章 `delay: 52` 之后才入场。** 抽帧验证要取镜内 55f 以上
  （全局 = 镜起点 + 55），否则会误判「印章没渲出来」。
- 落款字距 0.44em 是上限，再大就和印章抢位置；去字距会让落款看起来不像手写。
- 大字超过 11 字要减字号（96 → 84），否则两端出画。
- 印章用 `screen`（暗底）或 `multiply`（浅底），由 `Seal` 组件自动判。
