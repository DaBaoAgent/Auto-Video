# 02 · 舆图推进

## 画面

一张做旧的舆图铺满画面：经纬网格 → 地名标签（3–4 个）→ 主力箭头 + 两道偏师箭头。
镜头缓慢推近，箭头从起点生长。

## 运动

| 时刻 | 动作 |
|---|---|
| 0–76f | 纸面 scale 1.00 → 1.06（`easeInOutCubic`） |
| 0f 起 | 经纬网格先出（opacity 0→0.10） |
| 4f 起 | 地名标签逐个淡入，错峰 6f |
| 10f 起 | 主力箭头沿路径生长（strokeDashoffset） |
| 22f 起 | 两道偏师箭头稍后生长 |
| 2f 起 | 顶行大字「二十万人南下」逐字入场 |

## 参数

| 项 | 值 |
|---|---|
| 推进幅度 | 1.00 → 1.06 |
| 地名标签 | 字号 26，楷体，`letter-spacing: 0.28em` |
| 城标（方形标记） | **y = 612–626**，别压在箭头上 |
| 箭头 | 主 8px / 偏师 5px，朱砂 `cin(0.72)` |
| 顶行大字 | 78px，stagger 5f，dur 20f |

## content 槽

| 键 | 赤壁取值 |
|---|---|
| `line` | 二十万人南下 |
| `date` | 建安十三年 · 秋 |

地名是硬编码在 `PLACES` 数组里的（赤壁用 襄阳/新野/江陵/夏口）。换选题改数组，
**不要**塞进 content——地名带坐标，属于版式不是文案。

## 已知坑

- **城标必须避开箭头路径。** 第一版城标压在箭杆上，看着像箭头断了。
  下移到 y≈612–626（箭头在 640 以下走）。
- 经纬网格 opacity 超过 0.12 会像坐标纸，0.10 才有「旧图」感。
- 推进幅度超过 1.08 会让地名标签出画，且暴露纸张纹理的平铺缝。
