# 06 · 城墙旌旗

## 画面

三层纵深：远山与江岸 → 墨色城墙（含垛口、砖缝）→ 一排朱砂旌旗插在墙头。
镜头横移，近景旗比远景旗移得快。

## 运动

| 时刻 | 动作 |
|---|---|
| 0–83f | 近景层 `translateX(-64 × pan)`，远景层 `-26 × pan`（2.5 倍速差） |
| 0f 起 | 每面旗 `skewX(sin(f×0.15+ph)×3.6)` 独立摆动 |
| 0f 起 | 右上竖排地名淡入（20f） |

## 参数

| 项 | 值 |
|---|---|
| 城墙 | `top: 846` 到底，`solid(0.9) → solid(0.97)` |
| 垛口 | 21 个，58×48，间距 96，`top: 808` |
| 近旗 | 9 面，宽 52–74，高 176–250，`top: 846 - h` |
| 远旗 | 8 面，宽 30–42，高 96–134，`top: 1014 - h`（比墙头低 96，制造纵深） |
| 旗面 | 朱砂 `cin(0.94) → cin(0.78) → cin(0.9)`，剪角 `polygon(0 0, 100% 0, 100% 86%, 50% 100%, 0 86%)` |
| 旗杆 | 5px 宽，`solid(0.96)` |
| 杆顶金饰 | 13px 圆，`gold(0.5)` |

## content 槽

| 键 | 赤壁取值 |
|---|---|
| `place` | 襄阳城头（竖排 4 字） |
| `date` | 建安十三年 · 九月 |

## 已知坑

- **旗面必须是朱砂，旗杆才是墨。** 第一版旗和城墙同为墨黑，整排看起来像栅栏。
  靠色相差把它们分开是这张卡的命门。
- **删掉多余的远旗。** 远旗太多会糊成一片纸片；8 面、opacity 0.55、下沉 96px 刚好。
- 城墙、垛口、旗杆、旗上墨痕全部用 `solid()`；只有地名文字用 `ink()`。
- **城墙渐变的深端保留 `rgba(20,17,14,0.99)`**，起点才用 `solid(0.95)`。
  两端都换 `solid` 会让城墙从近黑变成深墨，砖缝突然全部显形（实测整片底部 99% 像素变化）。
- 砖缝横向线 `rgba(239,230,210,0.06)` / 纵向 `0.045`，再亮就像瓷砖。
- 这一镜画面下半是深色，字幕 `tone: "paper"`。
