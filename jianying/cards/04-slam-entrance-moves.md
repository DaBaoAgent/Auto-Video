# 04 · 城门分开

## 画面

整屏是一座城门：上楣、左右城墙、门槛，中间两扇带门钉的大门从中心分开，
门洞里的暖光涌出来。左楣竖排「一仗没打」，门下砸一枚「降」印。

## 运动

| 时刻 | 动作 |
|---|---|
| 6–40f | 门扇左右各推开 286px（`easeInOutCubic`） |
| 8–34f | 门洞暖光宽度随门扇同步张开 |
| 4f 起 | 竖排「一仗没打」逐字入场（54px，stagger 5f） |
| 50f | 「降」印砸落 |
| 20–42f | 左侧细线向下生长 |

## 参数

| 项 | 值 |
|---|---|
| 门扇 | 530×830，从左右各推开 `286 × open` |
| 门洞光 | 宽 `2d + 24`，暖金 → `#f8f0da` → 暖金 |
| 上楣 | 高 120，`solid(0.94)` + 砖缝 |
| 左右城墙 | 宽 430，`solid(0.93)` |
| 门槛 | `top: 950`，`backgroundColor: solid(0.96)` |
| 门钉 | 18 颗，17px 圆，`gold(0.26)` |
| 印章 | 104px，`left: 908, top: 700` |

| 键 | 赤壁取值 |

## 已知坑

- **底色必须用 `backgroundColor`，不能写 `background: linear-gradient(...)` 再展开
  `...brick`。** 后者会被 `backgroundImage` 整层替换成透明，背景纸从底下透出来，
  在成片里就是一条硬边灰带。
- **城墙、门扇、门槛用 `solid()`，不要用 `ink()`。** 暗色主题下 `ink` 是亮色，
  整座城门会反相成发光的米黄块。
- **门扇渐变的两端要保留硬编码深色**（`rgba(24,21,18,0.98)` / `rgba(20,18,16,0.99)`），
  只把中段交给 `solid`。全换成 `solid` 会让门扇整体提亮、失去厚重感——
  `solid` 在浅底只到 `#24211c`，够不到原来那层近黑。
- 门扇的「砖缝」用 `repeating-linear-gradient` 叠在门板上，opacity 0.045–0.055；
  再高就像栅栏。
- 这一镜是全片最暗的场景，字幕必须 `tone: "paper"` 反白。
