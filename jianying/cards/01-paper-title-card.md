# 01 · 竖排年份字卡

## 画面

右半屏竖排大字（纪年），左侧一条朱砂细线 + 小字（人物/年龄），下方一枚朱砂印章。
左下用两笔远山淡影压住留白。整屏是纸，没有实体。

## 运动

| 时刻 | 动作 |
|---|---|
| 0–34f | 纸面淡墨晕开（`wash`） |
| 2f 起 | 竖排大字逐字 blur 入场（stagger 5f，dur 20f） |
| 12–38f | 朱砂细线从上往下长出 |
| 16f 起 | 小字逐字入场，颜色用朱砂 |
| 48f | 印章砸落（scale 1.62→1，7f） |
| 全程 | 纸面 1.03 倍缓慢推近（`push`） |

## 参数

| 项 | 值 | 说明 |
|---|---|---|
| 大字字号 | 156 | 竖排 5 字占满右侧 |
| 大字位置 | `right: 206, top: 112` | |
| 小字字号 | 54 | 楷体 |
| 印章 | 94px，`right: 792, top: 800` | 两字竖排 |
| push | `1 + 0.030 × easeInOutCubic` | 0.03 就够，再大就晃 |

## content 槽

| 键 | 赤壁取值 | 含义 |
|---|---|---|
| `year` | 建安十三年 | 竖排大字，建议 4–6 字 |
| `age` | 我五十三岁 | 小字，建议 4–6 字 |
| `seal` | 曹操 | 印章文字，**2 字**（竖排两行） |

## 已知坑

- **印章只放得下 2 字。** 3 字会溢出成三行、压住细线。要 3 字就把 `size` 提到 110 并下移 20px。
- **年份超过 6 字要减字号**：156 → 128，否则顶端出画。
- 小字用朱砂（`CINNABAR`）而不是墨，是全片唯一的「红字」例外——它的作用是让观众第一眼看到人物身份，别改成墨。
- 远山透明度 0.5 × wash，别调高，否则像水渍。
