# 09 · 一点引爆

## 画面

整屏是安静的纸。一点朱砂在中央亮起，冲击环一圈圈扩散，朱砂像墨一样在纸面
渗开，把下半屏染红。俯拍的水面开始反光。

## 运动

| 时刻 | 动作 |
|---|---|
| 0–14f | 中心一点朱砂点出（scale 0 → 1） |
| 8f 起 | 3 道冲击环依次扩散（错峰 7f，各自 easeOut） |
| 40–70f | 朱砂大面积升起（`rise`，`easeOutCubic`） |
| 同步 | 江面泛红（`multiply`，暗底 `screen`） |

## 参数

| 项 | 值 |
|---|---|
| 中心点 | 8px 圆，`cin(0.9)` |
| 冲击环 | 3 道，起始 8px → 640px，1.5px 描边，`cin(0.35)` |
| 朱砂面 | 从 `bottom` 升起 34%，`cin(0.88)` |
| 江面反光 | `radial-gradient(80% 60% at 50% 104%, cin(0.55), transparent 62%)` |
| 字幕 tone | `paper`（反白） |

## content 槽

无（纯图形镜）。

## 已知坑

- **这一镜之后必须换能量方向。** 顶点只出现一次，下一镜（S10）是余波，不能再炸。
- 朱砂面 `multiply` 在浅底上像真渗进去；暗底必须 `screen`，否则整块变黑。
- 冲击环不要用发光（`box-shadow` / `blur`），旧纸上的冲击是「墨扩散」不是「光爆」。
- 朱砂面升起高度 34% 是上限，再高会盖住字幕。
