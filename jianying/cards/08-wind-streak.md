# 08 · 风向线

## 画面

两个人物侧影站在高处（广袖、落地衣摆），风从左往右扫过纸面，
一道风线穿过他们之间。左下芦苇丛被吹斜。

## 运动

| 时刻 | 动作 |
|---|---|
| 0–81f | 纸面 1.028 倍缓慢推近 |
| 0f 起 | 风线以随机相位横向扫过（每道独立速度，1.2–2.4 px/f） |
| 0f 起 | 衣摆/广袖随 `sin` 摆动，相位与风线错开 |
| 0f 起 | 芦苇每片独立倾斜 |
| 20f 起 | 标注「东 南 风」淡入（字间加空格，不是 letter-spacing） |

## 参数

| 项 | 值 |
|---|---|
| 推近 | `1 + 0.028 × easeInOutCubic(f/81)` |
| 风线 | 15 条，1.5px，`ink(0.10–0.18)`，斜 8–14° |
| 人物 | 侧影，纯 `solid(0.88)`，无五官 |
| 芦苇 | 一丛多叶，从同一根部散开，`solid(0.42)` |

## content 槽

| 键 | 赤壁取值 |
|---|---|
| `label` | 东 南 风 |

## 已知坑

- **人物不要画五官。** 侧影一旦有脸就要正脸/表情，成本翻倍且容易崩。
  这一镜的语义是「在等」，背影比脸有用。
- 风线 opacity 超过 0.2 就像雨。0.10–0.18 才有「风」的透明感。
- 字间用空格（`东 南 风`）而不是 `letter-spacing`，楷体下空格的节奏更像写在纸上。
- 芦苇丛用 `solid`，在暗底上才不会变成发光的草。
