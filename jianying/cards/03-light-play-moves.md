# 03 · 光源熄灭

## 画面

一盏将熄的灯在画面中部，光晕从亮转暗、范围收缩；大字「刘表」随光褪去，
小字「卒」在余烬里落定。

## 运动

| 时刻 | 动作 |
|---|---|
| 0–40f | 光晕 opacity 1 → 0.25，半径同步收缩 |
| 2f 起 | 大字逐字入场（208px，stagger 6f，dur 22f） |
| 26f 起 | 「卒」字入场（82px，楷体，朱砂） |
| 全程 | 画面整体偏暗（`Paper dim={0.12}`），暗得更快于光衰减 |

## 参数

| 项 | 值 |
|---|---|
| 大字字号 | 208（两字竖排） |
| 「卒」字号 | 82 |
| 光晕 | `radial-gradient(50% 42% at 50% 52%, …)`，暖金 → 透明 |
| dim | 0.12，全片唯一压暗的一镜 |

## content 槽

| 键 | 赤壁取值 |
|---|---|
| `person` | 刘表 |
| `mark` | 卒 |
| `month` | 八月 |

## 已知坑

- **光衰减要比文字快。** 光和字同步暗，观众会以为在淡出，不是「人死了灯灭了」。
  文字保持到最后 0.3s，光先走。
- `dim` 超过 0.15 纸纹就消失了，整屏变成灰色块。
- 「卒」必须用朱砂，别用墨——它是这一镜唯一的红色信息。
