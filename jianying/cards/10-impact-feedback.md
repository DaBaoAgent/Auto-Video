# 10 · 火场

## 画面

整屏是火。11 片焰舌从画面底部立起，前层亮、后层暗，交错出天际线的起伏。
火星向上飞散，船影在火里只剩黑色轮廓。画面持续微抖。

## 运动

| 时刻 | 动作 |
|---|---|
| 0f 起 | 每片焰舌独立摆动（`sin`，各自相位） |
| 0f 起 | 火星持续上升（`220 + seed()×420` px，循环） |
| 全程 | 画面 `translateX/Y ±2px` 抖动（`impact-shake`） |
| 0f 起 | 船影固定在火前，不参与抖动（造纵深） |

## 参数

| 项 | 值 |
|---|---|
| 焰舌数量 | 11 片（前层 7 + 后层 4） |
| 焰舌形状 | **渐收的贝塞尔**：宽底 → 细腰 → 收尖，不是椭圆 |
| 湍流位移 | `feTurbulence` + `feDisplacementMap`，强度 **降档使用** |
| 前层渐变 | `#ffd08a → #ff7a33 → #c8341a` |
| 后层渐变 | 更暗（`#ffb85c → #f2621f → #7d1a08`），不露深色尖 |
| 火焰基底 | 底部铺一层实心渐变，防止焰舌交叠处漏出暗天空 |
| 字幕 tone | `paper` |

## content 槽

无（纯图形镜）。

## 已知坑

- **不要用椭圆 + 强位移。** 椭圆经 92 强度湍流位移后必然塌成圆拱，怎么调都不像火。
  焰形靠贝塞尔路径（宽底、细腰、收尖），湍流只负责把边缘撕碎。
- **必须铺火焰基底。** 焰舌之间会漏出背景天空的暗色，看起来像黑色尖缝。
- 后层不要比前层亮，否则会从前面透出深色尖端。
- 抖动幅度 ±2px；±4px 就开始晕，且和字幕打架。
- 这一镜是顶点，时长给足（2.8–3.0s），不要为了压时长削掉。
