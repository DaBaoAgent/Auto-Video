# 07 · 一线展开

## 画面

大片空纸。正中一行大字，下面一条 3.5px 的主水线从中心向左右展开，
江面淡墨、几道水纹、一只小舟。右上竖排小字标注地点。

## 运动

| 时刻 | 动作 |
|---|---|
| 2–30f | 主水线从中心向两侧生长（`easeInOutCubic`） |
| 22–52f | 江面淡墨浮起（`water`） |
| 22f 起 | 9 道水纹横向缓移（速度 1.6–2.6 px/f，按序号错开） |
| 4f 起 | 大字逐字入场（86px，stagger 4f，dur 20f） |
| 22f 起 | 小舟从左往右漂 |
| 34f 起 | 地点标注淡入 |

## 参数

| 项 | 值 |
|---|---|
| 大字 | 86px，`letter-spacing: 0.16em` |
| 主水线 | 3.5px，`ink(0.86)`，`top: 758` |
| 江面 | `top: 762`，高 320，`ink(0.07) → ink(0) ` |
| 水纹 | 9 道，长 150–312，`ink(0.13)`，1.5px |
| 小舟 | 64×30，`left: 430 + f×2.2`，`top: 726` |

## content 槽

| 键 | 赤壁取值 |
|---|---|
| `line` | 天下只剩一条江 |
| `place` | 长江 · 赤壁（竖排） |

## 已知坑

- **这一镜的价值是「空」**，别加东西。空纸 + 一条线 + 一只舟已经够了。
- 江面/水纹/主水线在暗色主题下变成亮丝，恰好是月光感——**保留 `ink()`，
  不要改成 `solid()`**。只有小舟是实体，用 `solid()`。
- 主水线长过画面宽度的 90% 就失去「一线」的感觉，`draw` 最大到 1.0 即可。
- 水纹速度差要够大（1.6 vs 2.6），否则像整体平移。
