# 验收准则与已知坑

## 一、硬门禁（任一 FAIL 不算交付）

| 项 | 判据 | 实测口径 |
|---|---|---|
| 分辨率 | 1920×1080（横版）/ 1080×1920（竖版） | qa_film `--width/--height` |
| 帧率 | 30 fps | ffprobe `r_frame_rate` |
| 帧数 | `round(duration × fps)` | 940 帧对应 31.333s |
| 编码 | h264 + aac | ffprobe |
| 音频 | 48 kHz / 双声道 / 192k | ffprobe |
| 积分响度 | **-17.5 ~ -15.0 LUFS** | ffmpeg ebur128，目标设在 -16.3 |
| 真峰值 | **-3.0 ~ -0.3 dBFS** | 目标设在 -1.1，留 0.5 dB 给 AAC 过冲 |
| 黑帧 | 全片无黑帧 | qa_film 抽帧 |
| 字幕 | ≤ 14 字/条 | build_srt `--max-chars` / align `--max-chars` |
| 镜长 | 每镜 2.0–4.0 s | build_shots 告警（E3 定版均 2.69s） |
| 镜界 | 落在静音窗内（±0.06 s 边距） | build_shots 打印 |
| **帧间亮度** | **P99 < 1 灰阶，> 3 灰阶的跳变 = 0** | 见「五、频闪预算」 |
| 总帧数 | 等于 `round(音频时长 × fps)` | 按句累加会丢静音，E3 曾差 96 帧 |

## 二、画面准则

1. **一镜一个动效。** 一种手法全片只当一次主角。
2. **落定后要呼吸。** 关键信息落定后留 ≥0.5s 静止；印章砸落后不要立刻切。
3. **末帧必须收得住。** 抽帧只抽中点会漏掉一半问题——元素出画、光效没落定、
   字幕压画面，全部在末帧暴露。
4. **字幕 scrim 不能露边。** 只用「线性渐变 + 径向遮罩」，别用纯径向渐变
   （盒子顶边会在暗底上现形）。深底镜用 `tone: "paper"` 反白。
5. **红底镜字幕必须单独验。** 朱砂满屏时墨字完全读不出来，要反白。
6. **质感靠材质不靠渐变。** 纸感 = 纸纹 + 帘纹 + 颗粒 + 暗角 + 层间投影；
   纯渐变会滑向「PPT 风」。
7. **剪影永远比底深。** 见 `themes.md` 的 solid 槽。
8. **底图活在纸里，不在纸上面。** AI 静帧必须放进 `Paper()` 内部
   （`BgContext`），叠在卡片之上会把卡片白页一起 multiply 压掉。
9. **静态的东西必须真静止。** 纸纹、衬底、划痕、灰尘都不许逐帧重抽或位移；
   需要动的只有相机、墨点与人物。

## 三、已知坑（都实测过，别重犯）

### 音频

| 现象 | 根因 | 修法 |
|---|---|---|
| 真峰值凭空少 3 dB，掉出门禁 | ffmpeg 从 mono 升 stereo 按 1/√2 衰减每声道，同相双声道测响度时又补回 3 dB | 自己写双声道母版（两声道同一信号），**不要**用 `-ac 2` |
| 响度达标时峰值偏低，两道门禁打架 | 软限幅压太狠，PLR 只剩 12.9 | 先迭代增益定响度，再二分拟合限幅上限钉峰值 |
| 940 帧被削成 936 | 音频比视频短 0.05s，`-shortest` 按音频裁 | 音频侧先 `apad` 再 `-shortest` |
| 某行配音截断 | 该行字/秒超 6.4 | 改稿缩短，不是在 preset 里调 speed_factor |

### 画面

| 现象 | 根因 | 修法 |
|---|---|---|
| 暗底上城墙反相成发光米黄块 | `ink()` 绑 text 槽，暗主题 text 是亮色 | 实体改用 `solid()` |
| 暗底上印章/朱砂色块变黑斑 | `multiply` 在暗底等于乘成黑 | 换 `screen`（`useIsDark()`） |
| 一条硬边灰带横在画面下方 | `background: linear-gradient(...)` 后接 `...brick`（含 `backgroundImage`）被整层替换成透明，背景纸透出来 | 底色用 `backgroundColor` 兜底 |
| 字幕遮罩在暗底露出矩形边界 | 纯径向渐变投影到暗底，盒子顶边现形 | 线性渐变 + 径向 mask |
| 火苗像圆拱 / 像石头 | 椭圆 + 高强度湍流位移，形状必然塌 | 收尖的贝塞尔焰舌，位移只负责撕边；另铺一层火焰基底防漏暗天空 |
| 一排旗子像栅栏 | 旗和城墙同为墨黑，没有色差 | 朱砂旗面 + 墨黑旗杆 |
| 翻牌背面字重叠、描边发黑 | 3D 背面没有独立层 | 逐格漫染替代翻牌 |
| 道路硬折角 | 折线直接连线 | 中点二次贝塞尔平滑 |
| 路面在暗底上消失 | 路面是地被不是剪影，`solid` 压得比底还深 | 路面用 `ink()`，暗底变「月光照路」 |
| 门扇/城墙整片变亮，砖缝突然变明显 | `solid` 统一替代了原来硬编码的更深的渐变端（`#181512`/`#141110`），而 `solid` 在浅底只到 `#24211c` | 渐变**两端保留硬编码深色**，只把中段交给 `solid`（硬编码的深色在暗底上本来就是对的） |
| 字幕带整片由暖转灰 | 主题化时把 scrim 的 `shade` 绑到 `text`（中性黑），丢掉了原来的暖黑 `rgba(24,8,5)` | 浅底固定暖黑 `rgba(24,8,5,0.74)`，只有暗底才用纯黑并加大到 0.80 |

### 工程

| 现象 | 根因 | 修法 |
|---|---|---|
| `npx remotion still` 直接 SIGTERM | Remotion 没有内置浏览器 | 加 `--browser-executable` 指向 Edge |
| `render.log: No such file` | 输出目录没建 | 先 `mkdir -p out` |
| 静帧和成片对不上 | 改了代码但没重渲整片 | 静帧只验证构图，交付前必须整片重渲 |
| 半帧累积错位 | 镜界取整后没校正 | build_shots 的「帧级连续性校正」不能删 |

## 五、频闪预算（2026-10-26 定，E3 付的代价）

观众说的「画面在闪」有四个源头，单看静帧一个都发现不了，必须逐帧量亮度。

**量法**（几秒跑完全片）：

```bash
ffmpeg -v error -i 成片.mp4 -vf scale=192:108 -f rawvideo -pix_fmt gray - | python -c "
import sys,numpy as np
a=np.frombuffer(sys.stdin.buffer.read(),dtype=np.uint8)
n=192*108; L=a.reshape(-1,n).astype(np.float32).mean(1)
d=np.abs(np.diff(L)); print('均值%.3f P99%.3f 最大%.3f'%(d.mean(),np.percentile(d,99),d.max()))
"
```

判据：**P99 < 1 灰阶；> 3 灰阶的跳变必须 0 处**（切镜帧除外，按 shots.json
的 `from` / `from+frames` 前后各排除 1 帧）。

| 源头 | 现象 | 修法 |
|---|---|---|
| 逐帧亮度抖动 | `sin(frame*2.1)` ≈ 10Hz，±2.5% 全画幅 | 删掉整层，不做「曝光闪烁」 |
| 片门闪白 | 每 6.5s 一次、2 帧曝光跳变 | 删掉，改用暖调与暗角 |
| 纸纹逐帧位移 | 360px 平铺接缝横切画面，整帧跳 8 灰阶 | `backgroundPosition: '0px 0px'`，纸纤维静止 |
| 字幕衬底随字幕开关 | 字幕间空 1–3 帧就掉 30 灰阶（117 条字幕 = 117 次闪） | 抽成 `CaptionVeil` 常驻层 |
| 粒子每帧重抽 | 灰尘 15Hz、划痕 7.5Hz 全换位 | 改常驻粒子 + 连续漂移 |

定位方法：注释掉 `OldFilm` / `Ornament` 分别渲染同一帧对比，再用分块差值
（8×6 网格）看差异集中在画面哪一带——**差异集中在底部就是字幕层的问题**。
