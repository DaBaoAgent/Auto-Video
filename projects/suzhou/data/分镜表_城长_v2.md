## 一、总原则：把第八节 1–8 条变成五条硬规矩

1. **全片只切一次。** 唯一硬切放在 136.0 s，从 1896 跳到现在（园区）。其余 10 个章节边界全部用运镜、雾、水光、卫星淡入缝合；遮蔽转场不算硬切，但每处只能用一个手法，不叠用。
2. **每个章节一条不同的主轴。** 相邻章节的镜头运动方向必须不同（推 / 拉 / 东移 / 西移 / 升 / 降 / 低飞 / 环绕），上北下南的屏幕方向不变。
3. **信息越密，镜头越静。** 带数据卡、地图网格、引线标签的镜头，运动指数 ≤ 1；运动指数 ≥ 3 的镜头不同时承载超过 3 个标签。
4. **轮廓要有闭合，数字要有出处。** 城墙、八门、山塘线、运河、环线、年轮都用"描线闭合 + 数字"表达扩张；未核实的面积/长度先标"待核"，不上屏。
5. **水是缝合线，不是背景。** 太湖 → 运河 → 山塘 → 护城河 → 金鸡湖，同一条水光带在 0/6/30/58/110/136/147 s 反复出现，片尾与年轮重合。

## 十、与现有样片 / 数据的差异

1. **时长**：`timeline_draft.json` 现为 154.948 s，配音稿为 149.0 s；本表按 149.0 s 重排，需要先改 timeline 再改 `SAMPLE_ERAS`。
