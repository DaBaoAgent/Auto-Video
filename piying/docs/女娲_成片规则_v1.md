# 女娲视频 · 成片规则与需求规格 v1

> 确认日期：2026-10-25 ｜ 生效范围：自《女娲》起的所有后续视频项目
> 说明：炎帝成片不重做。本规格是新规则的首次完整落地，后续项目默认继承。

## 0. 总纲（最高优先级铁律）

**全片每一幕的动效密度必须对齐炎帝前 30 秒样片——动画多、动态多。严禁出现炎帝成片 30 秒后那种"大部分画面是动态文字撑场"的状态。**

## 1. 段落范式（混合模式）

| 段落类型 | 范式 | 说明 |
|---|---|---|
| 概念科普段 | 图标卡片 | 知识卡片 + 平涂图标/符号的入场、移动、变形动画，文字只做辅助层 |
| 故事叙事段 | 剪影/皮影场景 | 剪影角色 + 场景连续演绎（动作、行军、大场面） |

执行细则：
- 动工前由我方审读口播稿，逐段标注类型，产出《段落分配表》交用户确认后才开工
- 名场面（捏土造人、炼石补天、斩鳌足撑天等）**强制**剪影大场面演绎，不得降级为图标卡片
- 女娲以**人首蛇身经典剪影**贯穿故事段出场（蛇尾可盘绕、摆动、游走、腾空翻转）；概念段不出场

- 三视图选用规则（由我方按场景决定）：
  - **front（正面）**：正对镜头、介绍定格、章节卡、海报式构图、对话感
  - **side（侧面）**：行走 / 侧行 / 位移过场（水平移动 + 上下浮动模拟游动）
  - **back（背面）**：离去、眺望、远景意境
- 尺寸层级：特写 = 画面高 45-60%；中景 = 25-35%；远景 = 10-15%（可多实例小尺寸排布，同时计入"同屏运动元素"密度指标）
- 动效方式：整体位移 / 上下浮动 / 旋转 ±2° / 缩放呼吸；**PNG 为静态单帧、无待机帧序列**，动效全部来自变换与环境互动
- 渲染规范：Canvas 绘制时 `imageSmoothingEnabled = false`，保持像素锐利
- **后续剧集**：角色三视图由我方用 ImageGen 生成（本剧集沿用用户资产）

## 2. 密度硬指标（逐幕量化核验，三项同时满足）

1. **文字面积占比 ≤ 30%**：字幕 + 标题等文字总覆盖面积不超过画面 30%，其余 70% 由动画图形/场景占据
2. **每 2 秒一个新动效点**：任意 2 秒窗口内必有新元素入场 / 旧元素退场 / 运动状态切换
3. **同屏 ≥ 5 个运动元素**：任意时刻画面中同时运动的图形元素不少于 5 个（图标、装饰、图形、角色等）

**手机可读性（2026-10-25 用户裁定，与密度指标同级执行）**：视频主要在手机端观看，所有关键元素按 1920 画布以下限执行——标签文字 ≥ 60px、内容文字 ≥ 64px、角色/关键图形 ≥ 170px 高、单镜主要元素 ≤ 5 个保证每个都看得清。禁止"一小排+小字"的桌面端构图。

**人物居中构图（2026-10-25 用户裁定）**：主要人物默认居中位于画面中线（x=960），名字卡/标题置顶、附属卡横排收底；VS 对峙等对称构图以中线为轴两边均衡；第一幕按用户特别要求三人横排（问号置顶 + 三等分卡排）。

节奏与时长：
- 单镜时长维持 **2-5 秒**（沿用现有节奏，不加快剪辑）
- 配音总时长锁死，**直接复用现有配音**，密度靠单镜内多元素并发动效实现
- **纯文字画面豁免**：章节大标题、片头片尾、金句总结等结构性文字画面允许存在，但合计 ≤ 全片时长 20%

## 3. 视觉分层（四层叠加）

1. **静态深底**：深色底，保持画面干净
2. **持续微动氛围元素**：漂浮粒子、光斑、漂移网格/纹样，背景始终有生命感
3. **分段主题背景**：每个大段落换一套主题氛围（随叙事变化，如创世暖光 vs 灾劫冷色）
4. **动态场景舞台**：背景本身可运动——地平线推移、山峦视差滚动、光影/天气变化，强化时空流动感

色彩管理：
- 全片**一套主色系**（沿用前 30 秒同款），保证整体感
- 每段仅切换背景氛围色 + 1~2 个点缀色

## 4. 字幕层

- **2026-10-25 用户裁定：改用炎帝样式**——底部通栏字幕条（深色底 0.62 + 金色左边条 + 白字黑描边 + 64px 大字号），关键词金色高亮（女娲/伏羲/共工/母系社会/人文之母/补天/造人/神话/童话等）
- 此裁定覆盖此前的"字幕参与场景"方案（Q5），全片统一执行
- 排版纪律：字幕条占底部 H-156~H-56 区域，场景元素底部避让 924px 线（样片已按此调整：泥土地面、泥人列、章节卡元素全部上移）
- 保留既有字幕规则：无标点、一次一句、大字号
- 时间轴必须来自音频停顿检测（既有规则不变）

## 5. 转场

- 维持现有固化规则：**温和**；禁止全屏色块扫屏、禁止高频闪白（历史返工两次的铁律）

## 6. 音频

- 直接复用 `output/006_女娲/配音.json` 时间轴与现有 wav，不动音频层
- 仅在关键动效点（大元素入场、场景切换、重音落点）加**少量点缀音效**，不铺满
- **不加背景音乐**

## 7. 验收流程

1. **首期交付：正片片头 30 秒密度样片**（mp4）
   - 2026-10-25 确认改为**两段式共约 41.3s**：A 段 0.0-30.1s（概念范式：钩子+女娲登场+妈妈类比）+ B 段 40.3-51.6s（故事范式：捏泥人甩泥点）；30.1-40.3s 预告段样片中省略（正片保留）
   - 一次验收两种段落范式，达标后全片照此施工
2. **核验方式：逐幕量化核验报告**——每幕一行数据（文字占比 % / 动效点数 / 同屏运动元素数）+ 关键帧截图；不达标项列清单返工
3. 样片三项密度指标全部达标后，才进入全量制作
