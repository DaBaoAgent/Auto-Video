# laolang · 人物定稿规格参数（玄奘 60 秒样片，2026-11-10 冻结）

> 本文是玄奘 60 秒样片最终人物定稿的**唯一参数表**。源码：`toon-cast/lao_body.ts`、`toon-cast/lao_cast_full.js`、`toon-cast/lao_poses.js`、`toon-cast/toon.ts`、`toon-cast/lib/toon.js`。
> 冻结快照：`toon-cast/archive/v20261110_stable/`（`MANIFEST.sha256` 校验）。
> **改比例、发型、脸型、手臂结构前，必须先重出设定图给用户审核；不得直接改这里。**

## 1. 设计空间与比例（冻结）

| 项 | 值 |
|---|---|
| 设计画布 | **600 × 1000**（逻辑单位）；侧视人物朝右 |
| 地面 | `sole y = 975` |
| 腿长 | **125**（上一版 250 的一半） |
| 躯干 | 约 **360** 高，最宽 **248** |
| 头 | 约占全高 **1/4** |
| 手臂 | 比上一版短 **1/3**；手掌与鞋放大 |
| 线 | 平涂色块 + 硬边阴影 + 粗细变化墨线；线色 `#241726`（墨紫褐） |
| 眨眼 | `CAST.lidAt(t, seed, [强制闭眼时刻])`，30 fps，周期 0.5–2.3 s |

`lib/toon.js` 是把 `lao_body.ts` 追加到 `toon-cast/toon.ts` 后，用 `build_toon.py` + esbuild 编出的 IIFE（全局 `TOON`）。`CAST.draw(slot, LAO_FULL[slot], opts, side)` 把 600×1000 的人物画到页面。

## 2. 三种基准脸型 / 三种发型（已验收）

| 角色 | 脸型 | 发型 | 辨识物 |
|---|---|---|---|
| 领队 | 长脸（基准，`face: 'long'`） | 三七分侧分头，露额头，不戴帽 | 红围巾、马灯 |
| 记录员 | 圆脸（横 ×1.12 / 纵 ×0.90） | 秃顶 + 两侧短发 | 圆眼镜、挎包 |
| 挖掘工 | 方脸（横 ×1.08 / 纵 ×0.97，下颌再加宽 6%） | 板寸 | 宽檐帽、镐 |

个体差异用 `faceK = { fx, fy, nose, eye, jaw }` 在基准头型上再调（见第 6 节）；`age: 1` 加皱纹，`browCol` 改眉色。

## 3. 五官参数（`opts` 字段）

`browY / browIn / eyeW / eyeH / lid / pupil / lookX / lookY / open / smile / teeth / tongue / jaw`

- `browY` 眉高（负值上抬）、`browIn` 眉间压紧、`eyeW/eyeH` 眼形、`lid` 上眼睑（1 = 闭眼）、`pupil` 瞳孔大小、`lookX/lookY` 瞳孔方向、`open` 张嘴、`smile` 笑、`teeth` 露齿、`tongue` 舌、`jaw` 下颌下坠。
- 已验收的 7 个表情：平静 / 好奇 / 紧张 / 吃惊 / 用力 / 咧嘴 / 大笑；表情表见 `出稿/018_玄奘/08_人物设定/02_表情表_侧脸.png`、`03_表情表_正面.png`。
- 旁白描述时闭嘴（`mo ≈ 0.26` 是合唇）；人物不对口型，旁白是画外音。

## 4. 侧面结构铁律（v20261110 修正，所有人物）

1. **一律朝右**，不要镜像成朝左；页面需要朝左时整体 `scale(-1,1)`，不改人物源码。
2. 近侧（右）肩窝在**人物中线**；上臂从中线出。鲤鱼 v4 单臂结构的肩/肘/腕 x 都是 **300**，垂直穿过躯干前方，手在前腰中线。
3. 远侧（左）肩/上臂**完全藏在身体后**：不画肩片、不画半截上臂、不画远侧手。只有需要双手的动作才用 `farFront: true` 把远侧手放到身前。
4. 平时站立：除提灯、锡杖、长矛、书/镐等持物外，手臂**垂直向下**。
5. 持物：手臂伸直向前，或上臂向下、前臂向前下方**反向屈肘约 45°**；手掌画在杆/灯之后，**盖住**杆身/提梁，形成握持。
6. 动作库特例：05 抬头右手在眉/眼上方；06 低头头低 17、肩下沉；13 合十手掌并拢；14 跪拜两腿折到身后；15 打坐去掉双脚与小半截身体；16 提灯手抬到胸前；20 惊讶后退连退约 3 小步；23 擦汗只有右手在额头，左手藏住。
7. 动作库 01–03（行走 / 奔跑 / 停步）用 `straightArm: true`：右臂伸直垂在身侧，随脚步前后交替摆动；01 领队马灯挂在摆动的手腕上；停住后回垂直站姿。全片其它走戏不受影响。

## 7. 单臂结构（鲤鱼 v4，2026-11-10 用户定稿）

同一套 toon 管线在鲤鱼项目里固化成更严格的单臂结构，玄奘人物也按此校：

- 人物朝右；近侧右臂从人物中线 `x=300` 垂直向下（`drawArm([300,496],[300,590],[300,680], true)`）。
- 远侧左臂**完全不画**：无左肩片、左袖口、左手、第二只手。
- 道具不手持，放脚边/腰侧，不挡右臂。
- 人物画布 600×1000；单人 PNG 输出 **1200×2000**，鱼 **2200×1240 RGBA**；总表 **1900×1500**。
- 不用 CDN 字体；用本机 SimSun / KaiTi。
- 参考实现：BB-Video 的 `styles/laolang/carp-pipeline/`（`lao_cast_carp.js`、`lib/toon.js`、`PIPELINE.md`；未随本仓库提交）。

## 9. 自检

- 侧视：远侧手是否彻底消失？近侧手臂是否从中线出、垂直向下？
- 持物：手掌是否盖住杆/提梁？有没有第三只手？
- 比例：腿 125、躯干 360×248、头 1/4；三人同场时高矮/胖瘦/脸型能否一眼分开？
- 表情：先停一拍再动；惊讶先定住再眨眼/张嘴；旁白时闭嘴。
- 线条：平涂 + 硬边阴影，线宽有粗细变化；没有干净矢量边。
