# laolang · 60 秒样片制作方法（玄奘，2026-11-10 定稿）

> 本文把玄奘 60 秒样片的**做法、参数和验收**固化下来。人物见 `CHARACTERS.md`，动作见 `ACTIONS.md`，风格见 `STYLE.md`。
> 样板工程：`work/xz-film-60/`（页面 `index.html` 与快照 `toon-cast/archive/v20261110_stable/index.html` 逐字节一致，SHA-256 `a797cbb1…`）。

## 0. 成片结论

| 项 | 值 |
|---|---|

## 1. 输入与配音合成（现成配音，不重录）

### 输入

| 输入 | 说明 |
|---|---|
| `配音.wav` | 用户原声；`出稿/018_玄奘/配音.wav`，取 0–62.16 s（l1–l19） |
| `口播稿.txt` | `出稿/018_玄奘/口播稿_定稿.txt` 第 1–3 段；每行一个自然段 |
| `brief.md` | 事实表 + 屏幕文字表；画面上每个字只能从这里来 |

### 合成方式

`make_vo.py` 把现成配音**只做截取、转 48 kHz 立体声**，不重录、不变声；用「静音候选 + 字数/时长一致」的 DP 对齐，输出句级 + 词级时间轴。

```bash
python scripts/laolang.py vo projects/<名字> \
  --src 配音.wav --text 口播稿.txt --lead 0 --cut 62.16
```

产出：

- `audio/narration.m4a` / `audio/narration.wav`（48 kHz / 2 声道）
- `timeline.json` / `timeline.js`（`lines[].words[]` 词级时间）
- `paragraphs.js`、`script.json`（`bgm:false`）

页面按词取时间：`cue('l16', '走')` → 该词在旁白里的 start；所有动作/镜头/音效都挂在词上，保证「说到哪、画面到哪」。

### 已知坑

- ffmpeg 的 `-t` 必须放在 `-i` **之前**（输入截断），否则尾部被削。
- 本机 44.1 kHz 单声道 AAC 会卡住：先 `-ar 48000 -ac 2` 再编码。
- 段落间停顿有时 < 0.22 s，不能只靠 `silencedetect` 切段，必须 DP 对齐。

## 2. 分镜与页面结构

### 分镜

- **19 句旁白 / 17 个分镜**（另有 2 个短切：8.56–9.22、9.22–10.8）；每镜一个 `F.info('illustration', a, b, { group })`。
- 每镜必须有**不同的运镜**，不允许全片一个慢推；镜头表见第 3.3 节。
- 屏幕文字只有：`西游记`、`明`、`西游记 · 明`、`唐 · 五百年 · 明`、`大唐大慈恩寺三藏法师传`、`石槃陀`、`五座烽火台`、`一分钟样片`、片名 `玄奘`。

### 页面骨架

```js
PROMO.compose({
  bpm: 84, offset: 0, grain: false, tail: 0.2,
  theme: { bg: '#14110d', fg: '#efe3c4', ink: '#efe3c4', muted: '#b7a98a', accent: '#b23a2b', ... },
  captions: { max: 18, font: '"Noto Serif SC", "SimSun", serif', weight: 500 },
  build: (F) => {
    const G = PROMO.laolang(F, {
      seed: 'xz-toon-lao',
      boil: 0.04,            // 极低线条抖动
      drawings: 30,          // 每帧绘制
      captions: { max: 18, size: 37 },
    });
    const L = G.lib, lao = L.lao, ACT = window.ACT, ST = window.STORY;
    const S = 0.26;          // 1000 设计单位 → 260 世界单位
    const SW = 170 * S;      // 一步的世界长度
    // G.shot(a, b, (u, t) => { ... });  G.pause(...);  G.write(...);  F.sfx(...);  F.section(...);
  },
});
```

- **人物**：`CAST.draw(slot, LAO_FULL[slot], opts, side)` → `L.xfDraw(c, -300*s, -975*s, 600*s, 1000*s)`；`side()` 朝右，`sideL()` 镜像朝左，`front()` 正面。
- **步态**：`ACT.walkCurve({ t0, t1, x0, x1, L0: SW*2, phEnd })`；脚落地时刻用 `ACT.footfalls()` 配 `F.sfx(ft.t, 'step')`。
- **镜头**：`camPush(K(t, [[t0,x0],[t1,x1]]), y, z)`；`K` 是平滑缓动关键帧。
- **题字**：`G.write(text, { x, y, size, at, until, color, kind })`；最后 `F.coverAt(60.6)`。

### 暗角 / 罩染（风格的一部分）

页面在 `build` 末尾包一层 `F.render`：在每帧上叠一个径向渐变（中心透明，0.55 处 `rgba(4,14,13,.10)`，边缘 `rgba(2,9,9,.62)`），再叠一层 `rgba(12,34,32,.07)` 青绿墨色。作用是压住四边、让中间人物和灯火跳出来。不是后期滤镜，是画面的一部分。

## 3. 画面稳定参数（用户定稿，2026-11-10）

### 3.1 基础

- 逻辑画幅：**4:3 片门 960×720**，输出 1920×1080 / 30 fps。
- `drawings: 30`（每帧绘制）、`boil: 0.04`（极低线条抖动）。
- **关闭逐帧 gate weave**（`wx/wy = 0`）；灯光频闪幅度 **0.008**；颗粒**静态**（`ox/oy = 0`、固定 `gr[0]`、alpha 0.10）；**删除逐帧随机灰尘 specks**；保留静态 paperize 纹理、halation、vignette。
- 快频动态降速：风线、沙粒、沙带、云、烛火、鸟、火星。

### 3.2 人物景别 / 头位

- 有人物的全身镜头：人物大小 **0.24–0.26**（`S` 或略小）。
- 头部靠近画面**横中线**（720 高约 `y = 360–430`）。
- 脚下留白约 **100–160 px**（720 高）。
- 不切头、不切脚；坐/跪姿必须完整。
- 特写镜头也改成全身/中全景，不用大特写切掉身体。

## 4. 声音

### 4.1 音效设计（`sound.js`）

11 个事件：`step` `door` `doorStop` `dust` `wind` `room` `drip` `flame` `whoosh` `glint` `stamp`。

- `step`：3 个变体（thud + paper），脚步声跟着 `ACT.footfalls()` 的实际落地时刻。
- `door`：窄带噪声沿共振频率慢慢升上去再落下来 + 首尾两下木头敲击，是现场合成，不是采样。
- `doorStop` 门轴停住；`dust` 尘土；`wind` 洞里空风；`room` 房间底噪；`drip` 水滴；`flame` 火苗；`glint` 金环细响；`stamp` 题字印章。
- **每个动作一个声音，不要每个动作都配**；最大的声音是安静。

### 4.2 混音

- **无 BGM**（`script.json` `"bgm": false`）；旁白 + 音效。
- 26 个音效点；旁白说话时自动去掉 21 个轻音效（渲染器按人声区间处理）。
- 目标响度 **-16 LUFS**、真峰值 ≤ **-1.5 dBTP**；样片实测 -16.1 / -1.4。
- 音效位置：第一幕门/脚步/风/尘/水滴/金环/印章；第二幕沙漠风、寺庙房间底噪、夜路脚步、月光刀、清晨风、片尾印章。

## 5. 渲染

### 整片（默认）

```bash
python scripts/laolang.py render projects/<名字> --fps 30
# → out/video-16x9.mp4（1920×1080 / 30 fps，内置 -16 LUFS 响度归一）
```

### 长片 / 低内存：5 段渲染再拼接

样片实际分 5 段，避免 62 秒页面在 Chrome 里长时间空转：

```bash
node lib/render.mjs <项目> --from 0     --to 15.55 --fps 30 --out out/segA.mp4
node lib/render.mjs <项目> --from 15.55 --to 33.1  --fps 30 --out out/segB.mp4
node lib/render.mjs <项目> --from 33.1  --to 47.04 --fps 30 --out out/segC.mp4
node lib/render.mjs <项目> --from 47.04 --to 55.44 --fps 30 --out out/segD.mp4
node lib/render.mjs <项目> --from 55.44 --to 62.2  --fps 30 --out out/segE.mp4
# concat 五段（视频流直接拼），音频单独：
node lib/render.mjs <项目> --audio          # → out/audio.wav
# 音频 loudnorm 后与画面合并，精确裁到 62.200 s
```

- 页面最后一行保留 `window.__lint = () => [];`：62 秒版 lint 在 Chrome 里会长时间空转，渲染时跳过，成片另做逐帧 QA。
- **不要用 CDN 字体**：stable 页面已去掉 `<link>`，避免新页面加载卡住；字体用本机 Ma Shan Zheng / KaiTi / Noto Serif SC / SimSun。
- 封面：`node lib/render.mjs <项目> --cover`（60.6 s 帧）。

## 6. QA（验收标准）

```bash
python scripts/laolang.py qa projects/<名字>          # ffprobe / loudnorm / blackdetect / 解码
python scripts/laolang.py short-qa out/video-16x9.mp4 review/shortqa   # 逐帧（需 numpy + Pillow）
```

- **规格**：62.200 s / 1920×1080 / 30 fps / 1866 帧；H.264 + AAC 48 kHz 双声道。
- **画面**：无黑帧；无 ≥1.2 s 冻结；逐帧无意外闪帧/跳帧；无计划外白闪。
- **人物景别**：全身 0.24–0.26、头靠横中线、脚下留白 100–160 px；不切头脚。
- **声音**：-16.1 LUFS / -1.4 dBTP；无爆音；旁白清楚、音效不抢人声。
- **交付**：1080p + 720p + 封面 + 分镜总表 + 说明 + 字幕。
- **误报**：12.5 张/秒线条抖动、眨眼、镜头切换会被 pop 检测标成尖峰，逐帧看接触表确认，不算跳变。

## 7. 复用到新题材（步骤）

1. 写 `brief.md`：3–5 条事实 + 每条事实的画面证据 + 屏幕关键词 + Off limits。
2. 写 `storyboard.md`：逐句画面、人物动作、运镜、音效点；**分镜没写清不要写代码**。
3. `python scripts/laolang.py new projects/<名字> --title "片名"`。
4. `vo`：现成配音 + 口播稿 → 词级时间轴；改稿后先 `--check`。
5. 改 `index.html`：场景函数、镜头、人物调用、`F.sfx`；人物/动作**不要改** `toon-cast/`。
6. 改 `score.js`（可选）与 `sound.js`；默认 `bgm:false`。
7. `check` → `stills` 抽帧 → `render` → `qa` → `deliver`。

**红线**：任何人物/动作改动，先回到 `toon-cast/` 出一版设定图给用户审核，不要临时改页面里的参数。
