# 上海美影 1980 手绘赛璐璐（`laolang`，老狼请客式）

一帧：一幅青绿、橄榄、赭黄、锈红的手绘装饰绘景前，站着平涂的赛璐璐角色——细而活的深褐勾线、少量硬边阴影、夸张的长鼻子和大眼睛；画面被放进一个 4:3 的圆角胶片门里，有颗粒、轻微片门晃动和一点褪色。它像一卷 1980 年上海美术电影制片厂的动画短片：人物是画的，世界是画的，但世界比人物更松、更像一幅画。

> 这种风格学习的是 1980 年《老狼请客》那一代上美影手绘动画的**工艺与画面语言**：赛璐璐角色 + 装饰绘景 + 4:3 片门 + 民乐小乐队。**绝不复制**原片的角色、造型、题字、笑点、镜头或旋律。下面的角色、绘景、题字都是本风格自己的。

## 0. 安全

- **不复制任何上美影作品的角色、造型、服装、道具、题字、片头片尾或音乐。** 只学工艺：平涂、勾线、绘景、片门、节奏。新片的角色必须自己画。
- **真实人物不做漫画像。** 历史人物用壁画、剪影、背影或象征物来演；需要正脸时，用原创的、没有真实相貌特征的替身。真实事件中的受害者不做滑稽表演。
- **不使用原片音频、截图或赛璐璐片作为素材。** 研究可以看片，成片里的每一帧都要自己画。

## 1. 适合什么产品

- 中国历史、民间故事、寓言、成语、地方风物：需要“旧”“手作”“讲故事”的气质的题材。
- 人物驱动的小故事：一个和尚、一队考古队员、一个手艺人、一只动物；有表情、有停顿、有一个小转折。
- 品牌或产品里带“手作、地方、传统、慢”的一面；不适合纯软件 UI、实时数据、密集数字对比。
- 不适合：需要精确图表和大量数字的讲解（用 `swiss` / `blueprint`）；需要真实素材出镜的新闻（用 `newsreel` / `collage`）；需要极快节奏的促销（用 `launch` / `pop`）。

## 2. 本质，以及它不是什么

- **它是“画出来的戏”**：绘景是舞台，角色是演员；镜头是观众的眼睛。全景里人很小，该给表情时直接切大特写。
- **它是有手工痕迹的**：平涂色块、细而活的勾线、颜料在纸上的颗粒、背景的干笔触和斑驳；线条在连续画稿之间轻轻抖动。
- **它是克制的**：颜色不鲜艳，动作不光滑，音乐不铺满；留白、停顿、一个眼神比十个特效有用。
- **不是现代扁平插画**：不要干净的矢量边、均匀的圆角、完美的对称、无纹理的纯色块。
- **不是水墨 / 剪纸 / 皮影**：它是手绘赛璐璐，有明确的色块和勾线，不是墨晕、刀刻或透光皮革。
- **不是美式黄金卡通**（`goldenage`）：没有橡皮管式的疯狂物理、没有每一下都配打击乐；它的幽默更冷、更生活。
- **不是滤镜**：不能拿真实照片或原片截图加纹理；每一笔都要自己画。

## 3. 颜色

- 绘景：青绿 `#1d403f #2c5450 #3f6b60 #5d7f6d`，橄榄 `#5f682b #7f8840`，赭黄 `#8f6633 #b98a49 #d3aa63`，米白 `#efe3c4 #e2d0a8`，锈红 `#a34c32 #c06a45`，墨褐 `#2a211a`。
- 角色：三套低饱和的工作色（灰绿 / 赭黄 / 棕），皮肤暖赭，金环 `#d8a53f`。
- 分工：青绿和橄榄是“世界”，赭黄和锈红是“人待的地方”，米白是“脸和衣”，墨褐是所有的线。朱红 `#b23a2b` 只留给题字或最重要的一个标记，全片不要超过两处。
- 光线是画出来的：用大块半透明的暖色/冷色，不要用现代的镜头光晕或渐变叠加。

## 4. 字

- 标题用毛笔字（`Ma Shan Zheng` / `KaiTi` / `STKaiti`），颜色是朱红或米白；小字用宋体（`Noto Serif SC` / `SimSun`）。
- 字号（逻辑单位，短边 720）：标题 64–96，小字 18–26，说明 30–40。标题不要贴顶，至少离上沿 12%。
- 字是“写上去的”：标题逐字弹出（`G.write(..., { pop: true })`），不要滑入、不要现代弹跳；小字直接出现。
- 屏幕上少写字：画面能说的，不要用字重复旁白。绘景里的招牌、门牌、题壁可以手写进画面（不属于 DOM 字，注意事实核查）。

## 5. 动作

- **12.5 张/秒**（`drawings: 12.5`）：动作有台阶感，不要 60 帧的顺滑。
- 线条抖动：`boil: 0.38`，连续画稿之间轻轻动；要定住时用 `G.pause` / `G.still`，不要关掉全片的抖动。
- 走路有预备和跟随：脚落地、身体下沉、帽子/衣角晚半拍；手臂是弯的，不是直棍。
- 表情靠眉眼和嘴：先给一个停顿，再动；惊讶时先定住，再眨眼或张嘴。
- 不要匀速移动：`K(t, [[t0, v0], [t1, v1]])` 用平滑缓动；大动作前有预备，结束后有回收。

### 5.1 步态（走路的铁律：不许滑行）

- **脚在着地期相对地面静止**。`footStep(ph, L, lift, r)`：着地期占周期的 `r≈0.56`，脚相对身体以每周期 `-L` 的速度后移，恰好抵消身体的前进；摆动期（`1-r`）脚抬起、从身体后下方平滑摆到前下方。着地期内脚的世界位置必须逐帧不动——这是「不滑行」的唯一标准。
- **相位必须与位移积分绑定**：`dφ = dx / L`（身体每前进一个步长，步态完成一个周期）。不要用 `ph = t * freq` 驱动走路，那必然滑行。在 `build` 里用数值积分预生成「位移 → 相位」采样表（`walkCurve`），帧内查表。
- **减速 = 位移曲线的尾部**：位移 `g(u)` 结尾一阶导为零（如 `1-(1-u)^2.2`），步频自然跟着慢下来；最后 1/3 可以让步长也缩短到 6 成（小碎步收尾）。
- **停步三要素**：① 位移冻结（`x` 恒定）；② 相位冻结在**跨立站姿**（`ph ≈ 0.06–0.14`，两脚一前一后自然分开，不要并脚也不要大弓步）；③ settle：最后一步落地瞬间身体下沉 1.6 个逻辑单位、膝盖微弯（`limb` 的 `b` 加大）、躯干轻微压缩，然后回正。停步后除了眨眼和看的方向，什么都不许动。
- **手臂与同侧腿反相**：前臂 `sin(2π·ph + π)`（前腿相位 `ph`），后臂与后腿（`ph+0.5`）反相；摆幅 `armAmp ≈ 10–13`，手肘滞后一点（跟随）。推门、提灯等有任务的手从摆臂姿态平滑过渡到任务姿态，任务结束后收回。
- **身体起伏每周期两次**（每只脚落地时身体最低）：`bob = -2.2·|sin(4π·ph)|`，走路强度渐弱时衰减。

### 5.2 五官

- 旁白描述人物时**闭嘴**（`mo ≈ 0.26` 是合唇），只有用力、惊讶等情绪才张嘴；旁白是画外音，人物不对口型。
- **眨眼**：每人自己的节拍（周期 2.4–3.4 s 错开，占空比约 5%），闭眼用 `blink` 传 1。
- 剧情表情：看高处（门牌）用 `lookY < 0` + `browUp` 挑眉；推门用力用 `brow` 压眉 + `mo` 半张；惊讶用 `eyeWide`（眼睛放大、瞳孔缩小）+ `browUp` + 张嘴露齿。
- 看的方向由 `face`（头转，绕脖子 ±0.24 rad）和 `look` / `lookY`（瞳孔）一起完成；停步后 `face` 转向目标，人整个「看过去」。

## 6. 镜头和转场

- 4:3 片门（`academy: true`）：在 16:9 里左右留黑，圆角，颗粒，片门晃动。
- 舞台式构图：全景里角色小，背景大；需要表情时直接切大特写，不要慢慢推。
- 镜头可以慢推、横移“读”一幅壁画或一面墙；不要手持、不要甩镜、不要花哨转场。
- 转场就是切。需要收尾时用暗场（`veil`）或圈入圈出（`G.iris`），不要叠化。

## 7. 声音

- 音乐：民乐小乐队——竹笛、琵琶式拨弦、低音拨弦、弦乐铺底、木鱼、小锣；五声音阶，84–96 BPM。说话时笛子和铺底退后，拨弦和低音保留一点脉搏；停顿处可以全停。
- 音效：砂石脚步、旧木门吱呀、门轴停住、洞里空风、火苗、金环细响、印章。每个动作一个声音，不要每个动作都配。
- 最大的声音是安静：在关键转折前让音乐停住，只留环境声。

## 8. 这个媒介独有的动作

- **门的转开**：一扇旧木门绕铰链向内转，门缝先漏出一条暖光，再慢慢铺到地上；尘土在光里浮起来。
- **读壁画**：镜头沿一面墙横移，人物在旁白点到时进入画面中心；被点到的细节反光（金环、眼睛）。
- **画中人看回来**：壁画上的人头微微转向观众，眼睛先动，嘴再动；只用一次，用来收尾。
- **手电/马灯的光池**：光不是镜头光晕，而是画在墙上的几块半透明暖色。
- **胶片片门**：圆角、颗粒、轻微晃动；不是后期滤镜，是画面的一部分。

## 9. 绘景

- 绘景是“画”出来的：大块有机形状 + 干笔触 + 斑驳颜料 + 深色勾线；不要用规则的几何形。
- 崖体、山、树、云、水、室内墙面都由 2–4 层色块叠出来；每层有深色轮廓和内部纹理。
- 纸纹：`paperize()` 会把颜料颗粒和纸纤维压进绘景；每张绘景只做一次，缓存在 `PL` 里。
- 绘景坐标是 960×720（4:3 逻辑页），`cliff()` 和 `mural()` 各是一整张；`xfDraw` 让它们跟着同一个相机。

## 10. 人物

- 三个原创考古队员：`arch(x, y, s, pose, dir, id)`，`id` 0/1/2 分别是领队（ lantern ）、记录员（眼镜/挎包）、挖掘工（宽檐帽/镐）。
- 体形：领队高瘦、记录员矮圆、挖掘工肩宽；同一场戏里保持比例。
- 脸：长鼻子、大眼睛、粗眉；帽子/眼镜/围巾用来在一眼之内区分。
- 平涂 + 硬边阴影（`cel`），线宽 2.1–2.3；四肢用 `limb`，是弯的。
- 走位：步长约为身高的 1/3（身高约 110 逻辑单位 → `L ≈ 36–40`），步频 1.5–2 步/秒；三人错开入画时间与相位，走路时一个看路、一个看崖壁、一个点头，不整齐划一。
- 站位：停步后三人间距约 80–90 逻辑单位，领队距门一步（手能按到门板），其余两人在侧后方；影子随人，停步后影子也定住。
- 过肩剪影：`archSil(x, y, s, id, glow)`，黑色背影 + 一道暖色轮廓光；头、肩、帽子要能读出来。
- 壁画人物：`muralMonk` / `muralHorse` / `muralApe`，平涂在墙上，不是赛璐璐角色；头可以单独转。

### 10.1 toon 定稿人物（可选）

## 11. 常见的坑和自检

- **绘景变成扁平矢量**：检查大形状是否有干笔触、斑驳、深色轮廓；如果看起来像 PPT，重画。
- **角色太可爱 / 太现代**：检查鼻子、眉弓、手和鞋；不要圆头圆脑的吉祥物。
- **4:3 被拉伸**：检查左右黑边和圆角片门；逻辑页应是 960×720。
- **矩形变成椭圆**：任何矩形/门板/画框都要用 `sub()` 把边细分，否则平滑路径会把四角磨圆。
- **镜头太顺**：不要全片一个慢推；该切就切，该停就停。
- **字贴顶 / 字重叠**：标题离上沿 ≥12%，小字和标题分开至少 40 逻辑单位。
- **音乐盖过人声**：所有旋律层默认在说话时退后；只有拨弦/低音可以 keep。
- **金子太多**：金环/金饰只在一个地方发光；全片不要到处是金色。

## 12. 变化空间

- 颜色：把青绿换成靛蓝/灰紫，做成夜景；把赭黄换成土红，做成窑洞。
- 绘景：山林、洞窟、院落、集市、河岸；只要保持“大色块 + 干笔触 + 深轮廓”。
- 人物：换服装、帽子、道具；保持三种体形和一眼可辨的轮廓。
- 片门：`academy: false` 做宽银幕；`film: false` 做干净的数码版；`drawings: 10` 做更旧、更顿的节奏。
- 音乐：换调式（羽调/徵调）、换主奏（箫/唢呐/三弦），但不要引用现成旋律。

## 13. 接口速查

```js
const G = PROMO.laolang(F, {
  seed: 'my-film',
  drawings: 12.5,      // 每秒画稿数
  boil: 0.38,          // 线条抖动
  film: true,          // 颗粒/片门晃动
  captions: { max: 20, size: 36 },
});
const L = G.lib, lao = L.lao;
// 绘景（逻辑页 960×720，返回离屏 canvas，缓存在 lao.plates）
lao.cliff();  lao.mural();
// 把绘景放到当前相机下
L.xfDraw(lao.cliff(), 0, 0, G.W, G.H);
// 门：t 是影片时间，openAt 是“推”的时间，dur 是开启时长
lao.door(t, openAt, 0.72);
// 人物：x, 地面 y, 比例, pose, 朝向, id
lao.arch(x, groundY, 1.0, { ph: t * 7.4, walk: 1, lean: 0.8, mo: 0.3, push: 0, look: 1 }, 1, 0);

// 壁画：整体 + 单独人物

lao.muralMonk(x, groundY, 1.16, { turn: 0.2, look: 1 });
```

## 14. 60 秒样片定稿（2026-11-10，玄奘）

玄奘 60 秒样片把这一风格从「12.5 张/秒的手绘顿感」推进到「30 fps 稳定版全片」。做同类样片时按下面这套参数：

- **画幅**：4:3 片门 960×720，输出 1920×1080 / 30 fps；左右留黑。
- **稳定**：`drawings: 30`、`boil: 0.04`；关闭 gate weave（`wx/wy=0`）；灯光频闪 0.008；颗粒静态（固定 seed，alpha 0.10）；删除逐帧随机灰尘 specks；快频动态降速。
- **人物景别**：全身 0.24–0.26；头靠画面横中线（720 高约 y=360–430）；脚下留白 100–160 px；不切头、不切脚。
- **运镜**：每个镜头不同的推/拉/横移/跟拍/升降，不要全片一个慢推；19 镜的逐镜参数见 [`PRODUCTION.md`](PRODUCTION.md) 第 3.3 节。
- **声音**：旁白 + 音效，无 BGM；现成配音只截取/转 48 kHz 立体声，不重录不变声；用词级时间轴把动作/镜头/音效挂到词上；响度 -16 LUFS / 真峰值 -1.5 dBTP。
- **验收**：62.2 s / 1866 帧；无黑帧、无 ≥1.2 s 冻结、逐帧无意外闪帧；4:3 左右留黑不算黑帧。
- **代码**：必须用 `toon-cast/archive/v20261110_stable/` 的 `goldenage.js` + `laolang.js` + `toon.js` + `lao_poses.js` + `lao_cast_full.js`；页面与快照逐字节一致。
- **完整做法**（分镜、暗角罩染、音效事件、分段渲染、QA）：见 [`PRODUCTION.md`](PRODUCTION.md)。

## 15. 还不支持的

- 快速版（`--quick`）还没有为这个风格注册 `kit.js` 适配器：只能手写构图（本风格本来就是手写的）。
- 没有内置的口型同步：人物不说话，旁白在画外。
- 绘景是固定的几张：新的地点要自己写 `PL` 里的绘制函数（参考 `laolang.js` 的 `cliff` / `mural`）。
- 没有 3D 镜头：相机只有推、移、轻微旋转；不能环绕。
