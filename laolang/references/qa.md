# laolang 验收清单

> 样片标准：玄奘 60 秒样片（62.200 s / 1920×1080 / 30 fps / 1866 帧 / H.264 + AAC）。

## 1. 规格

- [ ] 时长 = 旁白 + tail（样片 62.16 + 0.2 = 62.200 s）
- [ ] 1920×1080 / 30 fps / 帧数一致（62.2 × 30 = 1866）
- [ ] 4:3 片门 960×720 居中，左右留黑；不是 16:9 拉伸
- [ ] H.264 + AAC 48 kHz 双声道；完整解码无错误
- [ ] 1080p 与 720p 各一份；封面；分镜总表；说明；字幕（如需要）

## 2. 画面稳定

- [ ] `drawings: 30`、`boil: 0.04`
- [ ] 关闭逐帧 gate weave（`wx/wy = 0`）
- [ ] 灯光频闪 0.008；颗粒静态；无逐帧随机灰尘
- [ ] 快频动态已降速（风线、沙粒、沙带、云、烛火、鸟、火星）
- [ ] 无频闪、无晃眼；放映机晃动已关闭

## 3. 人物景别

- [ ] 全身镜头人物 0.24–0.26
- [ ] 头靠近画面横中线（720 高约 y=360–430）
- [ ] 脚下留白 100–160 px
- [ ] 不切头、不切脚；坐/跪姿完整
- [ ] 侧视：远侧手消失；持物手盖住杆/提梁；没有第三只手

## 4. 动作

- [ ] 走路着地脚不滑（最坏漂移 < 0.3 逻辑单位/帧）
- [ ] 停步：减速 → 冻结在跨立站姿（ph 0.06–0.14）→ 下沉回弹
- [ ] 大动作有预备/回收；不是匀速
- [ ] 表情先停一拍再动；惊讶先定住再眨眼/张嘴
- [ ] 24 动作的修正点（05/06/13/14/15/16/20/23、01–03 直臂）没有被回退

## 5. 黑帧 / 冻结 / 闪帧

- [ ] 无黑帧（4:3 左右留黑不算）
- [ ] 无 ≥1.2 s 冻结
- [ ] 逐帧无计划外白闪/跳帧
- [ ] pop 尖峰逐帧确认：线条抖动、眨眼、镜头切换是误报；真正的跳变要修

## 6. 声音

- [ ] 旁白与口播稿一致；词级对齐无明显偏移
- [ ] 26 个音效点都在位；脚步挂在真实落地时刻
- [ ] 无 BGM（`bgm:false`）或 BGM 在人声下退后
- [ ] -16 LUFS（±1.5）/ 真峰值 ≤ -1.5 dBTP
- [ ] 无爆音、无削波、无长段死寂

## 7. 文案与风格

- [ ] 屏幕文字全部可追溯；没有多余字
- [ ] 不复制《老狼请客》的角色、造型、题字、笑点、镜头或旋律
- [ ] 真实人物不做漫画像；受害者不做滑稽表演
- [ ] 色彩：青绿/橄榄/赭黄/锈红/米白/墨褐；朱红只给题字或一个标记（全片 ≤2 处）
- [ ] 没有现代扁平矢量边、均匀圆角、无纹理纯色块

## 8. 交付

```bash
python scripts/laolang.py qa projects/<名字>
python scripts/laolang.py short-qa out/video-16x9.mp4 review/shortqa
python scripts/laolang.py deliver projects/<名字> \
  --chugao 出稿/<编号>_<选题> --name "laolang_片名_样片_1080p"
```

- [ ] `review/qa.json` 生成；QA 结论 OK 或人工确认项已记录
- [ ] 交付目录含 `.mp4`、`_封面.png`、`_字幕.srt`、`_署名.txt`
- [ ] 大文件不入库：`audio/`、`out/`、`review/`、`lib/` 由 `.gitignore` 排除
