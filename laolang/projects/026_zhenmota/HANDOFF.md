**风格实现（复现《老狼请客》质感的关键，别删）**

这一层是"整帧赛璐璐"，不在绘景里做，而在人物画完之后对整张画统一做一遍——否则人物和背景会分成两张皮。

1. **`lib/cel.js` + `opt.post` 钩子**（核心）
   `goldenage.js` 在每张画完成、叠加 halation 之前调用 `opt.post(buf, tq, {pxW,pxH,RS})`；`laolang.js` 把 `opt.post` 透传下去。`stills.html` 里：
   ```js
   post: (c) => CEL.frame(c, { seed: 11, exp: 1.04, gamma: 0.90, con: 1.06, sat: 1.05,
                               tooth: 0.100, wobble: 0.55, inkThr: 7, inkAmt: 0.60 })
   ```
   `CEL.frame` = `wobble` → `ink` → `grade` → `tooth`：
   - `wobble(amp)`：低频噪声双线性位移重采样，把尺子画的直边推歪 ±amp px，每帧同一 seed 不闪。
   - `ink`：3×3 高斯 → Sobel，阈值 `inkThr`；用 64×64 低频噪声当"断笔掩码"（0.52–1.0 相乘），墨色暖褐 `[40,31,24]` 随亮度微调，上限 `inkMax 0.62`。
   - `grade`：曝光 → gamma<1 提暗部 → 反差 → 饱和 → 分离色调（亮部 `liftR/G/B = 0.050/0.034/-0.016` 暖黄，暗部 `-0.008/0.004/0.030` 冷青）→ 黑位 `floor 0.010`（黑是暖褐不是死黑）。
   - `tooth`：中间调最重的颜料颗粒（按亮度调制）+ 2200 根横向纸纤维。
2. **绘景 `plate()` 链**：`inkEdges(c,26,0.50)` → `bandBreak`（软湿色带，不是硬边）→ `CEL.brush` 天空横扫 + 下半幅斜扫 → 上下渐变压暗 → `vignette(0.16)` → `mottle` → `punch`（按场次 PSAT 补饱和）→ `paperize(c, amt*0.50)`。
   `PSAT = { s2:1.08, s4:1.34, s7:1.10, s8:1.16, s9:1.44, s10:1.20 }`——绘景越亮越容易发灰，逐场补。
   **只在绘景上做 `punch`，整帧调色统一交给 `CEL.grade`**，两层都调会过。
3. **树**：`tree()` 用三层圆斑（暗→中→亮侧光）各画 10/13/7 个 blob + 9 片边缘叶，**不要**再用菱形/圆点拼冠（一眼矢量）。
4. **落地感**：`castShadow(x, gy, s, ang, a)` 在 9 处人物脚下画斜向椭圆影，`rgba(32,24,16,0.18)`。
5. 人物一律侧视 `CAST.draw(slot, OUTFITS[slot], opts, true)`；场景人物统一 `sideA/sideL`（dir=1 朝右、-1 朝左）。`lib/toon.js` 的赛璐璐阴影对比已加强（夹克 0.70/0.88、长袍 0.74）。
6. `runtime/` 已同步：`runtime/cel.js`、`runtime/goldenage.js`（post 钩子）、`runtime/laolang.js`（`post: opt.post`）。新工程只要 `post: (c)=>CEL.frame(c,{...})` 就能拿到同一套质感。
7. **第二轮修整（2026-11-11 夜，按质检意见改）**
   - 暗角：`vignette()` 与 `goldenage` 的 `VIG` 都从 `rgba(6,2,14,.42)` 冷黑换成暖褐 `rgba(56,38,24,.22)`，四角提亮 20–30 级；第 3 场另加的径向暗角 `.55 → .16`。
   - 黑位：`CEL.grade` 的 `floor 0.010 → 0.10`，纯黑抬到 `#1a1712` 一带。**注意**：反差的 `(v-0.5)*con+0.5` 会产生负值，必须 `Math.max(0,v)` 再套 floor，否则负值把黑位吃掉（树冠曾掉到 `#0a070a`）。
   - 纸纹：`CEL.tooth` 纤维 2200 根/0.028 → 3200 根/0.090，宽 0.9–3.1px、长 6–36px；横向为主，实测 `gx/gy ≈ 0.79–1.00`（各向异性达标）。

## 固定管线参数
### 渲染基础参数
- 人物缩放：S=0.45
- 地面y坐标：720
- 相机：`camPush(540, 520, 1.0)`
### 站立类动作统一晃动
所有站立动作均加自然呼吸晃动，避免人物僵硬：
```js
const sway = Math.sin(t * 1.2) * 8;    // 左右晃动±8像素
const breathe = Math.sin(t * 0.8) * 0.08; // 上下呼吸起伏
const phase = Math.sin(t * 0.5) * 0.2;  // 重心微移
```
### 走跑停参数
行走/奔跑/停步动作使用 `ACT.walkCurve` 驱动位移和步态相位，开启 `mode='march'`、`straightArm: true`，手臂保持垂直下垂随步伐摆动。
### 动作过渡规范
- 统一使用SMOOTH缓动函数：
  ```js
  const SMOOTH = (a, b, u) => {
    const q = clamp((u - a) / Math.max(1e-5, b - a), 0, 1);
    return q * q * (3 - 2 * q);
  };
  ```
- 用自写的 `mixPose` 函数对idle姿势和目标姿势的数值参数做插值，将插值结果通过 `opts.actPose` 传入绘制函数。
- 每个动作前0.1秒开始过渡，1.2-1.5秒过渡完成后保持目标姿势。
- 带布尔绘制标志的动作（如跪拜/打坐）需拉长过渡时间到2秒以上，前半段保持站立姿势逐步前倾/屈膝，最后再切换坐姿/跪姿绘制逻辑，避免腿部跳变。
### 文字标注规范
- 人物名：红色 `#b23a2b`
- 动作名：米白色 `#efe3c4`
- 使用 `G.write(text, {x,y,size,color,at,until,kind,font})` 标注。
