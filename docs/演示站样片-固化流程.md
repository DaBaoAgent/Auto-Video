# 演示站样片 · 固化流程

这条流程管的是**演示站（GitHub Pages）上每条管线那张卡的 10 秒样片**，和 `docs/交付规范.md`（正片定稿进 `out/`）是两件事，不要混。

## 一、片名规范

- **卡片上不显示样片名**：166 张卡统一只显示管线名（对齐「拼贴剪贴」「南方公园剪纸」「配音前端」这类没有片名的样片）。`build_site.py` 里 `title` 恒为空串，`app.js` 只有 `title` 非空才渲染 `《…》`，所以片名不会再上卡。
- 片名仍然要填，只作**档案与校验用**：写进 `samples.json.display_title` 与 `catalog/pipelines.json`、`pipelines/<key>/pipeline.json` 的 `sample.title`。取 4–6 字裸片名（如「河岸的午后」「孔雀窗」），不带管线名、不带"·"。
- 别为了让名字上卡去改 `data.js`：下次 `build_site.py` 会覆盖，且契约校验会挂。

## 二、站点版规格（写死）

| 项 | 值 |
|---|---|
| 画幅 | 16:9，长边 1024 → 1024×576 |
| 帧率 | 30 fps |
| 编码 | H.264 / CRF 30 / preset veryfast / yuv420p / faststart |
| 时长 | ≤ 10 秒（母版超 10.5s 直接报错） |
| 音轨 | 无（站点统一静音悬停播放） |
| 封面 | 同一帧导出 `site/media/<key>.jpg`，q 6 |

## 三、标题必须三处一致（硬门禁）

1. `site/assets/samples.json` → 该条的 `display_title`（**页面标题的唯一读取入口**）
2. `catalog/pipelines.json` → `pipelines[].sample.title`
3. `pipelines/<key>/pipeline.json` → `sample.title`（+ `sample.seconds`）

`tools/validate.py` 会比对 2 和 3，不一致直接 ERROR。只改 `data.js` 会被下次 `build_site.py` 覆盖；只改 1 会让契约校验挂。

## 四、一条命令做完

```bash
python tools/pack_sample.py --key wenyi \
    --master "review/wenyi_master_v7.mp4" \
    --title "午后的银杯" --poster 3.9 \
    --tagline "十秒横摇穿过文艺复兴长厅：窗边猫、举银杯的少女、画案上校比例的学者；午后侧光、天鹅绒宝石色、龟裂与黄釉。" \
    --push
```

脚本做的事：探母版 → 压站点版到 `samples-v3/<key>-10s.mp4` → 拷进 `site/media/` → 钉秒导封面 →
回写 `samples.json`（bytes / poster_pick / badge / source / 尺寸）→ 三处标题同步 → 可选改 tagline →
跑 `build_site.py` 与 `validate.py`（任一失败即退出，不许提交）→ `--push` 时 add / commit / push。

## 五、上线才叫改完

- 站点由 `.github/workflows/pages.yml` 在 **push main**（命中 `site/**`、`catalog/**`、`schema/**`、`tools/**`）时构建部署。
- **只改本地文件 = 线上没变**，这是最容易踩的坑。
- 推完核对三样：
  ```bash
  gh run list --workflow pages.yml --limit 1
  gh run watch <run-id> --exit-status
  # 线上 data.js 里该条的 title / mp4 字节数
  ```
- 页面还显示旧内容时，先 Ctrl+F5 强刷（`assets/data.js` 会被浏览器缓存）。
- 现在不会了：`build_site.py` 的 `stamp_index()` 给 `app.css` / `data.js` / `app.js` 挂 `?v=<内容哈希>`，
  资源一变 URL 就变，缓存自然失效。验收时看 `index.html` 里这三个链接都带 `?v=`。

## 六、卡片显示规范（改版式前先读）

- 卡片标题 = **中文管线名 + 小字 id**：`<h3><span class="nm">回形针风</span><span class="slug">huixingzhen</span></h3>`；
- 中文名过长只截断自己（`.nm` 负责 ellipsis），id 不换行、不截断（`.slug` 是 `flex:none`）；
- 卡片上**不出现**《样片名》：`build_site.py` 里 `title` 恒为空串，`app.js` 只在 `title` 非空时才渲染书名号；
- 想改版式就改 `site/assets/app.js` + `app.css`，改完本地 `file://` 打开 `site/index.html` 自查，
  并用一行脚本确认没有溢出：`document.querySelectorAll('.cap h3')` 里 `scrollWidth > clientWidth` 应为 0。

## 七、首页总样片（改动画前先读）

README 顶部那张动图不是手剪的，由 `tools/build_teaser.py` 从站点样片重新生成：

```bash
python tools/build_teaser.py            # 出 showreel.mp4 + teaser.gif
python tools/build_teaser.py --mp4-only # 只出完整版
python tools/build_teaser.py --gif-only # 只出首页动画（会另建一版快剪母版）
python tools/build_teaser.py --ids piying,shuimo2 --dry-run   # 换选片、看命令
```

- **完整版** `site/media/showreel.mp4`：1440×810 / 30fps / 21 段 × 2 s / 无音轨；README 的动图点开就是它；
- **首页动画** `site/media/teaser.gif`：600 宽 / 8 fps / 48 色 / 每段 1.2 s，GIF 单独建一版母版，标签按画布等比放大后缩到 600 仍能读清；
- **硬切，不做溶解**：溶解时两段标签会叠在一起糊成一团（试过，难看），21 次风格换场本身够强；
- 角标 = 中文名 + id + 右上 `序号/总数`，左上 `AUTO-VIDEO`；非 16:9 的样片用深色 pad 补边，**不用模糊底**（GIF 只有 48 色，模糊渐变会出色带）；
- 选片顺序按质感编排（工艺 → 绘画 → 笔类 → 数码笔记 → 花字贴纸），相邻两段不同材质；
- 换片只改 `DEFAULT_IDS` 或传 `--ids`，**别手剪**：手剪的下场是片名、时长、颜色对不上，下次没人能重跑。

## 八、验收清单

- [ ] 片名 4–6 字裸片名，仅作档案字段（卡片上不出现《》）
- [ ] `site/media/<key>.mp4` 是 1024×576 / 30fps / ≤10s / 无音轨
- [ ] `site/media/<key>.jpg` 与样片同一帧，人脸/主体没被裁
- [ ] 三处标题一致，`validate.py` 退出码 0
- [ ] Pages run = success，线上 `data.js` 里 title 已是新片名
- [ ] 改过样片就重跑 `tools/build_teaser.py`，README 动图里的那一段才是新的
