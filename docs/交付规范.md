# 交付规范（定稿归档）

这条规范对所有管线生效。**用户说「定稿」之后**，一律按这里执行：把定稿产物从临时/聊天目录整体搬进仓库 `out/`，不再散落在各管线 `projects/*/out/` 或个人目录里。

## 一、目录

```
out/
├── 01_血之海滩/           # 编号两位 + 片名，按编号排序
│   ├── 血之海滩_全片_插图重画版.mp4
│   ├── 血之海滩_全片_插图重画版.srt
│   ├── 血之海滩_封面_3x4.jpg
│   ├── 血之海滩_封面_4x3.jpg
│   └── 血之海滩_发布信息.md
├── 02_xxx/
└── _archive/              # 被新一代替换掉的旧定稿（不删除，只下沉）
```

- 编号从 `01` 起顺序递增，同一片子迭代出新版时不新增编号，只在同目录里替换文件，旧文件下沉到 `_archive/`。
- 目录里**只放最终交付物**：成片、字幕、封面、发布信息。中间产物（母版、crf 中间件、抽帧、联系表）留在管线工程自己的 `out/`，不进这里。

## 二、四件套

| 文件 | 命名 | 规格 |
|---|---|---|
| 成片 | `<片名>_<版本>.mp4` | 1080p / 30 fps / 有音轨 / −14.6 LUFS、峰值 ≤ −1.6 dBFS |
| 字幕 | `<片名>_<版本>.srt` | 与成片同源、同名 |
| 封面 | `<片名>_封面_3x4.jpg` | 3:4 竖版，给抖音/小红书/视频号 |
| 封面 | `<片名>_封面_4x3.jpg` | 4:3 横版，给 B 站/公众号 |
| 发布信息 | `<片名>_发布信息.md` | 严格按下面模板 |

封面要求：标题字用黄字黑边、字迹清楚无错字；画风与成片同一套（不许成片是平涂浓彩、封面却是写实摄影）。

## 三、发布信息模板（就用这个格式，不加别的）

```markdown
# <片名> · 发布信息

## 标题

<一句话标题，前 12 个字要能勾住人>

## 标签

#标签1 #标签2 #标签3 #标签4
```

就这两节：**一个标题 + 四个标签**。不要写简介、不要写平台参数表、不要写注意事项——那些由运营侧另行决定。

## 四、动作清单（定稿时按序执行）

1. 把 `out/<编号_片名>/` 建好（编号看现有最大号 +1）。
2. 成片与字幕改名后 `Move-Item` 进来（同名文件被客户端缓存过，换版本名如 `_插图重画版` 比解释省事）。
3. 出两张封面（3:4、4:3），按上表命名放进来。
4. 按模板写 `发布信息.md`。
5. 上一代被替换的文件 `Move-Item` 到 `out/_archive/`，不删。
6. `git add out` 后提交，commit message 用 `deliver: <片名> 定稿归档`。
