`pipelines/<id>/`，入口只调本地 `runtime/render.mjs`，不依赖任何外部 checkout。

处置表是唯一事实来源：[`tools/legacy_style_map.json`](../tools/legacy_style_map.json)，37 条逐条记 `already` / `equivalent` / `import`。

## 封装内容

每条管线现在都是自包含的：

| 目录 | 内容 |
| --- | --- |
| `runtime/` | 共享 `core.js` / `promo.js` / `autoscene.js` + 风格运行时 `<slug>.js` + `render.mjs` / `music.mjs` / `sound.mjs` / `bgm.mjs` / `lang.mjs` / `net.mjs` + `scores/`；MIT，随附 `LICENSE-upstream` / `LICENSE` |
| `template/` | 起步工程：`index.html`、`score.js`、`sound.js`、`brief.md`、`assets/manifest.js` |
| `references/` | 风格规范原文（`style.md`）、分镜模板、验收清单 |
| `scripts/` | `new` / `check` / `stills` / `render` / `probe` / `qa` / `deliver` 七个动作，只走本地 `runtime/render.mjs` |

## 本地复现

```powershell
cd pipelines\keli
python scripts\keli.py new projects\demo --title "试片"
python scripts\keli.py check projects\demo
python scripts\keli.py stills projects\demo --times 1,4,9
python scripts\keli.py render projects\demo --fps 30
python scripts\keli.py qa projects\demo
```

`render` 只读 `runtime/` 与本机 Chrome/Edge，缺浏览器时用 `CHROME_PATH` 指过去。

## 与 77 条自研内核渲染的分工

- 这 6 条是**单画法运行时**：一套 `runtime/<slug>.js` 对应一种画法，参数走 `score.js`，适合长片、带音乐与配音的成片。
- 77 条是**共享内核**：`vendor/runtime/stylekit.js` 的 14 个风格族 + 每条自己的 `SPEC`（形状表 / 色板 / 节拍），
  适合短样片与风格演示，抓帧统一走 `vendor/runtime/style-frames.mjs`。
- 两套都不调云端服务，也不读外部仓库路径。

## 已知限制

- `andiao` / `yugao` 是暗调片，QA 允许长黑场，LUFS 按 −16 而不是默认 −14。
- 6 条的 `runtime/` 是单条独立的，升级共享内核（`vendor/runtime/`）不会自动同步到它们；改内核要单独跑
  `tools/sync_runtime.py` 检查漂移。
